# 星杯本地工作与训练归档

本次归档保存2026年11月14日开始采集的本地代码、模型、训练数据、评测结果、人工对局和规则异常记录。

- 代码快照位于本归档分支，包含当时本地未推送提交和未提交代码。快照可能包含开发中的实现，不代表发布验收。
- 完整数据分包位于同名 GitHub Release，包含原项目、工作区证据、训练目录、线上模型快照和本机星杯服务配置。
- `files.jsonl.gz` 是逐文件索引，记录原路径、SHA-256、大小及存储对象。`archives.json` 记录数据分包和校验值。
- `restore.py` 可校验并恢复归档到指定的新目录。先下载所有附件，再运行 `python3 restore.py --assets 下载目录 --output 恢复目录`，需要本机有 `zstd`。
- 相同内容只存一份，原文件路径由索引完整恢复。超过512MiB的文件按块保存。
- 活跃训练继续运行，文件按采集时保存。日志记录读取长度及采集时间，SQLite使用在线备份。新生成文件属于下一次快照范围。
- 可重建的Python虚拟环境、安装包缓存、字节码、node_modules、Git对象目录、锁文件和未完成临时文件排除。依赖版本另存。
- 此归档分支不触发跟踪main的部署服务。
