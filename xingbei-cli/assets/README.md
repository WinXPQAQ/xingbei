# 星杯传说原版资源

本目录收录当前重构版运行所需的原版图片和字体，包括`legacy-assets.json`登记的牌面、角色头像、星石，以及四种字体、music背景纹理、牌背和治疗槽。克隆仓库即可运行网页版，无需另外下载原项目目录。

| 目录 | 内容 |
| --- | --- |
| `image/card/` | 基础牌、五系束缚专属牌、星石、原版指示灯与战纹/魔纹图标 |
| `image/character/` | 当前角色与已有开发场景使用的头像 |
| `font/` | 行楷、黄草、新魏和Suits字体 |
| `theme/` | music纹理、星杯牌背和治疗槽图片 |

来源为本地原项目`xingbei-1.6.7-source/`（星杯传说v1.6.7）；文件按原相对路径原样复制，未重绘、重编码或修改原目录。`manifest.json`列出每个资源的原相对路径、字节数和SHA-256，便于核对。网页继续使用英文URL，由`../legacy-assets.json`映射到原文件名。

原项目随附的GPL-3.0许可证原文保留为`LICENSE`，原README原文保留为`UPSTREAM-README.md`。资源继续保留原作者及第三方的适用权利，项目许可证不另行改写第三方素材的权利说明；完整代码与素材来源见[来源说明](../SOURCES.md)。

此目录是当前运行资源集，不是原项目所有素材的完整备份；未使用的音频、其他主题、角色及旧引擎仍保留在本地参考项目中。添加新角色或资源时，补入对应文件并更新清单与映射。原版采集工具仍需要另行提供完整原项目。
