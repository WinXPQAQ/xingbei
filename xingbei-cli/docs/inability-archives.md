# 无法行动的拦截与判负档案

按玩家合法已知信息判断确定性。真·摹影耗尽可行动手牌、兽魂警戒移除行动者最后一张牌会在支付前拦截；强制弃牌存在安全选择时，只开放能继续行动的组合。若实际执行造成恶意无法行动，在启动流程结束检查责任方并判负。随机启动摸牌导致无法行动则明弃全部手牌、重摸相同数量，直到可行动，不重复启动。

当前预拦截接入真·摹影、兽魂警戒；通用移牌追踪提供后置责任检查。其他英雄的复合效果仍需按实际规则审查，不能将临时失去手牌一律视作恶意。对他人的暗手牌不检查牌面来决定拦截。

每次实际判负生成独立 JSON 档案，包含初始配置、责任方、受影响者、技能、判断依据、完整回合状态、六人全部手牌与英雄状态、所有牌实例及区域、抽牌顺序、战绩资源、行动日志、牌移动和选择记录、公开历史。档案为深拷贝，不随游戏继续修改。

- 终端：默认 `~/.local/share/xingbei-logs/inability/`，可用 `XINGBEI_DIAGNOSTIC_DIR` 指定目录。
- 浏览器：自动下载 `xingbei-inability-时间戳.json`，同时尝试保存在当前站点 localStorage；浏览器配额不足时仍下载。
- 训练：当前运行的诊断目录内 `inability-forfeit-种子-序号.json`，另含规则版本、决策序列和复现命令。

这些文件含完整隐藏信息，仅供规则排查，不加入普通公开日志或模型观测。判负属于正常终局并留档；未知规则异常仍按训练约定暂停并保存现场。

验证：核心 Node 测试及训练接口测试；1440×900、390×844 隔离浏览器验证拦截提示、返回操作、完整 JSON 下载。隔离验证不代表所有英雄自然对局已经验收。
