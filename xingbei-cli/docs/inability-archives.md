# 无法行动的拦截与判负档案

按玩家合法已知信息判断确定性。真·摹影耗尽可行动手牌、兽魂警戒移除行动者最后一张牌会在支付前拦截；强制弃牌存在安全选择时，只开放能继续行动的组合。若实际执行造成恶意无法行动，在启动流程结束检查责任方并判负。随机启动摸牌导致无法行动则明弃全部手牌、重摸相同数量，直到可行动，不重复启动。

当前预拦截接入真·摹影、兽魂警戒；通用移牌追踪提供后置责任检查。其他英雄的复合效果仍需按实际规则审查，不能将临时失去手牌一律视作恶意。对他人的暗手牌不检查牌面来决定拦截。

每次实际判负生成独立 JSON 档案，包含初始配置、责任方、受影响者、技能、判断依据、完整回合状态、六人全部手牌与英雄状态、所有牌实例及区域、抽牌顺序、战绩资源、行动日志、牌移动和选择记录、公开历史。档案为深拷贝，不随游戏继续修改。

- 终端：默认 `~/.local/share/xingbei-logs/inability/`，可用 `XINGBEI_DIAGNOSTIC_DIR` 指定目录。
- 浏览器：自动下载 `xingbei-inability-时间戳.json`，同时尝试保存在当前站点 localStorage；浏览器配额不足时仍下载。
- 训练：当前运行的诊断目录内 `inability-forfeit-种子-序号.json`，另含规则版本、决策序列和复现命令。

这些文件含完整隐藏信息，仅供规则排查，不加入普通公开日志或模型观测。判负属于正常终局并留档；未知规则异常仍按训练约定暂停并保存现场。

验证：核心 Node 测试及训练接口测试；1440×900、390×844 隔离浏览器验证拦截提示、返回操作、完整 JSON 下载。隔离验证不代表所有英雄自然对局已经验收。

## 2026-11-04 用户裁定与选择约束

- 染污者弃2仅在手牌超过2且有可使用牌时开放，选牌组合必须保留至少1张可使用牌；否则摸2。
- 红衣主教驱魔式不得选择只剩1张非圣命格牌的自己。权能逆位变身、王车易位返回路径已核对：保留圣遗物、银制子弹与宝珠实例，新旧技能订阅随英雄替换更新。
- 星坠盖最后一牌后，可选启动摸1；没有可用牌时黄金律必选。交换仍自由，完整技能结束才按最终行动能力换牌。为获得行动条件而启动时，盖牌分支必须摸1。
- 传教士根据路标持有者是否有手牌约束摸牌和自弃；持有者空手、自身也空手时不可传道，自身只有1牌必须摸1并尽可能保留可用牌。持有者有牌且传教弃后空手，必须给予接收者可用的牌（存在时）。交换与事奉完整结束才判断换牌。
- 魔眼仅3张以上且有可用牌时开放弃牌路线；自弃保留可用，盖牌自由。完整结算后，有雷充能可雷光散射就不换牌，否则无合法行动时换牌。
- 充能摸0至4自由，空手时禁止摸0；盖牌前若手牌全不可用先明弃重摸，再盖牌且必须留至少1张可用。AI优先摸不超过手牌空位的数量，上限4。
- 兽灵只剩1牌不能弃；全不可用时必须摸1，之后允许换牌。
- 尚未启动、不可买合且无普通行动时，如果存在可供给行动条件的启动路线，不开放直接换牌；可选择提炼或启动。启动后仍按最终行动能力处理，不重新触发启动。

传教旧误判的实际原因是中间移牌记录的`inabilityCause`延续到整个启动结束，不是直接在弃牌中途判负。上述允许自由交换/盖牌的技能在完整结算末调用`allowActivationRefresh`消除该过时归因。通用`ensureActionableHand`检查技能行动（包括雷光散射），只有充能盖牌前显式要求手牌本身可使用。

本批不增加长期具体场景测试：现有148项核心、14项AI/训练接口通过，临时脚本核对选项与牌实例守恒；12局短跑覆盖72英雄。完整异常和判负归档继续保留，不宣称其他英雄所有分支已杜绝无法行动。
