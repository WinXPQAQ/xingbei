模块及限制：draws使用固定公开牌表仅扣自己初始已知牌，超几何估计攻击/防御种类和连刀储备；不看实际未来牌堆、不虚构可打的未知牌。附带离散来袭致命尾部概率，避免仅对平均伤害取爆牌阈值；仍是粗略活动/目标/防守概率，非完整多玩家响应树。no-draws也关闭此尾部补偿；风剑公共能量限制的来袭估算各消融共用。tempo仅给风剑需要独立普通行动的非圣光法术算积压，封印师不适用；通过联合分布计算，不把相关摸牌事件独立相乘。energy取消风剑两攻击牌造成的7分持有悬崖，首能量储备3、后续每份0.5，实际技能仍由可选搜索支付。allocation只给一份共享宝石未满足狂战需求期权，3分储备尺度按公开距离折扣，不逐队友重复累加。连刀保留期权仍是有限地平线近似，不声称期权估值问题全部解决；神官水神期权未直接删掉或退还。
