# economy-4 修正与独立确认

本轮不发布，生产默认仍v1.2；保留economy-3原行为及其未通过非劣的全部6912局。源码冻结SHA将在开跑记录中提供。

## 固定诊断

在读取轨迹前固定10对：两种非镜像英雄归属，各从候选负、同配置v1.2控制胜的记录中按seed/start/team取前5。20局真实引擎重放，winner和turns与原记录逐项一致；同状态比较策略选择，不把分岔后的随机抽牌差异作为因果证据。完整配置含heroIds，见confirmation/fixed-ten-pairs.json。

找到可解释语义错误：候选model.heal直接把治疗截至普通上限，契约已给3/4治疗的队友/敌人会被“+1治疗”错误降至2，真实引擎保留已有值。同状态30次angelBond比较中，候选因此选择给超限治疗的敌人加治疗，误认为能削减其治疗；例pair0控制轨迹turn82，天使5号蓝方误选红4号已有4治疗，旧版选蓝2号0治疗，实际前者不变、后者+1。该错误并不证明解释10对所有败局。

修正为与Game.changeHealing相同的增减边界，正增疗不会减少已有超限治疗。新目录v1.3-economy4；旧economy-3及所有生产基线未修改。

## 永久放弃诊断与有界例外

原候选2截断、旧版自对抗2截断对应3个物理局面，延长至900回合仍无胜者，300→900无非pass且物理状态不变。高牌使购买/合成不可用，负分出牌被pass=0压住，圣盾长期无人消耗。不是正常长局，原截断率仍在预登记1%内。

曾在开发中试验仅公开历史驱动的窄破盾进展例外，但独立审查指出当前模型对圣盾分支未枚举对方仍合法的应战，不能把模型内安全当作真实最坏情况安全；原候选两局死锁又是己方有盾、敌方无盾，并不满足例外条件。该例外在冻结前撤回，最终候选不强制负收益破盾、不改规则，也不伪造终局。保留高代价应继续放弃的回归，循环是已确认且未解决的有限规划局限，按既定截断≤1%门如实验收。

## 一次性新确认计划

在查看新holdout前固定120主种子120001–120120，四阵容×六先手×两颜色，候选-v1.2、候选-v1.0、旧默认-v1.2、旧默认-v1.0共23040局。风格另30种子124001–124030、候选/旧默认分别对flow/reserve共5760局，合计28800局。

固定全量后才汇总胜率，不按中途胜率扩样或停试，不混入旧结果。保留原总体≥53%、提升≥3pp及区间门、对v1.0和风格非劣、每对截断≤1%门。四阵容−5pp非劣同时要求边际95%和Bonferroni98.75%下界通过。

120簇是先验计划：开发样本非镜像SE约3.4pp，按四倍样本估计SE约1.7pp、同时区间半宽约4.2pp；仅为样本量依据，不保证通过。原先失败结果不合并为预注册成功。完整协议见confirmation/protocol.json。
