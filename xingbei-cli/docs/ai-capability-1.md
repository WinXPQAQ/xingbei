# 能力约束保牌评分修复候选

在普通行动规则纠错候选abc939877a12ecedd60b3d7e97eb5f7b4ae2d195上新增独立候选`experimental/economy-capability-1`。不修改历史策略目录、不切换默认v1.3、不发布。新增候选复制economy-4，planner逐字节不变，index仅改候选名与复用原trace模块；model只修保牌技能选项加分的能力条件。

原问题：handValue对带闪光陷阱、精准射击、天使之墙标记的手牌，每种统一+2，不检查持有者是否拥有该技能。神官因此为自己不能发动的精准射击/闪光陷阱保牌。

新规则使用隔离公共观测已有的真实getSkills技能ID，不靠英雄名字猜技能，也不因队友拥有技能而凭空增加赠牌价值。技能被禁用或移除时无加分；克隆间共享的能力ID列表冻结。三项条件如下：

- 闪光陷阱：持有者有该技能、手中有对应标记牌、存在目标；既有规则允许自己或任意玩家为目标，不要求敌方。
- 精准射击：有该技能、有对应标记的攻击牌、存在敌对目标。
- 天使之墙：有该技能、有对应标记牌、至少一个玩家没有圣盾；既有规则允许任意玩家，不限友军。

这里估值的是保留牌供下一次普通行动使用的选项，不是假称当前额外阶段还能使用法术。因此不以当前已完成行动阶段抹掉所有未来保牌价值。三项当前技能均不支付能量。候选依旧必须经过共用合法性适配选择本次实际动作。未加入假想将来赠给某技能队友的加分；现有显式赠牌分支继续按完整赠牌后的状态计算。

能力所有权是本次观测快照。当前六英雄三项均为固有技能；未来若引入挂载牌授予这些技能且模拟中移除该挂载，尚无动态能力来源更新模型，不能声称覆盖该扩展。手牌资格与圣盾目标可用性则按每个模拟分支的当前状态重新检查。
