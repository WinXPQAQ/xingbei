# 魔弓、贤者专项训练（2026-11-12）

## 本轮要回答的问题

保持结构化实体编码、候选动作评分和参数独立的价值网络，先检验：集中训练一个英雄的真实决策，能否使它在完整团队对局中发挥机制优势。第一阶段使用两个独立模型副本，不同时加入新的专属模块，避免把架构变化和专项采样混为一种效果。每局只有对应英雄的一席提供训练轨迹，其余五席冻结。

训练恢复 `standard` 规则：合成正常增加星杯，5杯获胜，也可削减敌方士气获胜。奖励仍只有终局团队胜负；提炼、盖牌、发动技能、造成伤害都不额外发奖励。截断局不当失败。魔弓或贤者不必亲自合杯，最终评价的是它所在团队的胜率。

当前士气训练第216轮模型原文件冻结，作为两份专项模型共同起点和对照；第417轮原基线也冻结。分叉时重置旧士气实验的优化器动量，之后每轮完整保存优化器与随机状态。线上体验服务不自动更换模型。

## 采样与更新

- 魔弓和贤者每轮各192局，轮流推进；64个模拟进程，GPU批量推理，更新批次64。
- 指定英雄轮换六个座位，固定阵营红蓝蓝红红蓝；其余英雄从70个可开局英雄中抽取，同局不重复。魔弓EX、只能变身登场的铸律者不直接入座。
- 其余五席的控制器按局均分：冻结第216轮、第417轮、当前规则AI、明确标为部分迁移的旧评分AI。旧1.5只支持初始六英雄，不伪装成魔弓或贤者陪练。
- 训练英雄按策略分布探索；冻结陪练使用确定性选择，与开发评测保持一致。其余五席不会更新，也不会混入学习样本。
- 策略学习率 `5e-5`，独立价值网络 `3e-5`；每轮2遍PPO，熵系数0.03，采样KL停止阈值0.02。价值网络沿用按来源对局分组的训练、验证回退机制。
- 先从完整对局检验跨回合准备与兑现，不人为制造“满能量满盖牌”的必胜局面。后续需要课程时再增加真实重放局面。

## 贤者真人参考

本地找到两局完整正常模式的贤者胜局，种子为1794411869825、1794412228845。它们只是两次真人示范，不能证明每一步最优，也不能证明策略泛化。

`training/entity/human-reference.mjs` 从记录状态重建**离线观测**，映射到当前合法候选，不把状态快照当可恢复的对局生成器。卡牌实体、位置、顺序、手限经过核对；隐藏手牌及牌堆顺序扰动不得改变编码。恢复声明过的放弃启动流程后，拆分子决策的最终操作必须与原人类操作一致，选牌集合允许顺序不同。爆牌等缺少完整最终选择的记录不猜标签。

两局分别得到88个子决策，共176个；包含行动意图、法典费用与目标、法术反弹、治疗抵扣等，不能把176当作176次独立行动。第一局参与前16轮贤者训练，第二局只记录选择一致率和交叉熵，不参与更新或选模。

第一局可见的实际打法包括：圣洁法典自伤4触发智慧法典补宝石；魔道法典选自己打1，再通过法术反弹继续调整手牌、向敌方兑现伤害；也有直接把魔道法典打向敌人的选择。参考保留了具体费用、目标和后续响应，不写成“总是打自己”或“总要多反弹”的硬规则。

真人参考以0.05权重加入策略损失，按原决策分组采样，避免多张牌的分解使其权重膨胀；不进入PPO轨迹、价值目标或奖励。主信号仍是新对局的胜负。第17轮起取消这一参考项。一致率只表示像不像示例，不等于玩得好；第二局也只是小规模开发诊断，不称独立强度验收。

## 评测与记录

每约一小时、当前完整轮次结束后评测。每个英雄使用144个配置，覆盖六座位与四种冻结陪练；候选模型和冻结当前模型运行相同配置，只替换对应英雄的一席。冻结对照可缓存。报告配对胜率差及按来源种子（六次轮换一簇）计算的95%区间。

记录该英雄的提炼、盖牌、行动选择、对敌实际攻击/法术伤害及技能日志，同时区分整局星杯/士气/判负获胜。技能日志可能一次发动多次记录；伤害不等于士气收益。这些统计用于解释打法变化，不作为奖励。重复开发评测只用于比较与选模，正式上线仍需新种子验收。

保存：`status.json`、每英雄`round-*.pt`及报告、`best-development.json`、`evaluation-latest.json`、`report.md`、`gpu.log`。每次检查点包含模型、词表、优化器、随机状态、规则版本、专项进度和父模型来源。每轮使用确定的独立随机种子，重启不会跳号或重复提交已完成轮次。

## 运行与停止

先用`prepare-specialists.py`创建包含当前源码、两份冻结模型和离线示例的独立目录，再在其中运行：

```bash
python training/entity/specialists.py RUN_DIRECTORY --games 192 --workers 64 --eval-games 144
```

在运行目录创建`PAUSE`文件，当前采样、更新及已开始评测自然完成后停止；删除该文件后用同一参数恢复。`--rounds 1 --games 24 --workers 24 --eval-games 24`用于独立的小批次流程验证，不把这组数据当强度结论。试运行目录与持续训练目录分开，不混合样本配置。

可预见无法行动判负按既定裁定完整归档后继续训练；其他规则或程序异常保存现场并停止，不自动无限重试。不要自行换线上AI。

本轮顺带修复评分器`terminalForecast`在分支士气期望值为小数时创建非法长度数组的问题：用相邻整数的概率分布保存该期望值，不修改真实规则中的士气。

## 贤者反弹链练习（2026-11-12）

用户最终指定的入口：正常行动阶段，贤者随机6手、2治疗、1宝石，必须选择两张异系牌对自己发动魔道法典，先1法伤、后1法伤。不是从已结算的反弹窗口开始，也不在此练习中比较圣洁法典。两段开场1伤不抵扣；后续反弹的治疗抵扣由模型决定。有合法同系组时必须反弹；目标只允许自己或唯一满手敌人。其他四席不参与，敌人无治疗、无技能、无状态，只按真实规则爆牌暗弃。实际牌序和摸牌均来自150张牌库，不读取未来牌。

入口没有两张异系牌的样本记为不适用，不伪造发动或记为失败。超过256次子决策的链记为截断，不训练。未知异常保存完整手牌、牌序、选择、待结算伤害和日志并停止专项。

规则层新增 `Game.damageSequenceSteps/getPendingDamage`，贤者魔道法典和法术反弹使用它记录已经公开宣布的后续伤害。按嵌套流程由内向外恢复：当前伤害不在待处理队列中，当前问题单独表达；队列包括后续目标、来源、声明伤害、技能、顺序与深度，不预言最终抵扣结果。正常结束、取消及胜负确定都会清理队列。伤害时点与先后顺序保持原样。当前仅这两项技能接入，不代表所有英雄的未来效果均已编码。

编码在动态问题尾部加入 pendingDamage 实体，并修复治疗问题丢失 context.skillId 的问题。张量格式仍为 entities-v7，专项检查点显式标记 `entities-v7+public-damage-plan-v1` 并扩展词表，运行快照记录源码哈希。新增token即使零初始化也可能改变注意力，因此迁移后先测初始对照，不声称行为等价。旧检查点、全局训练快照和线上模型保留。

专项从贤者第16轮检查点另开分支：该轮在原人类示范中的反弹目标匹配较好，但这不是证明它更强。策略使用原权重；独立价值头重新初始化，学习的是专项收益而非胜率。每轮512个随机入口，32个模拟进程，PPO两遍，独立价值网络MSE；每10轮在固定512个开发种子评测一次，另保留第0、1轮评测。随机状态、优化器、模型、词表和报告每轮保存。新增专项不替换在线AI，也不把专项伤害标签混入全局胜负样本。

唯一正向指标是对敌实际法伤（胜利后的过量部分截为15点有效收益）；己方任何士气下降都不合格，专项回报为-1，合格样本回报为有效法伤/15，没有反弹次数、用治疗、获得宝石的附加奖金。负回报只是训练约束的近似，不能保证策略永不爆牌。因此同时报告不掉士气比例、其Wilson区间、合格样本平均伤害、每次尝试的安全伤害，开发最佳按安全率优先、再按伤害排序。不能只拿合格子集的高伤害宣称完成。

`training/entity/sage-value.py` 提供 `estimate_sage_hand(table,x,y,a,b,c,d,e)`：光、暗分别计数，基础五系数量降序。固定初始治疗2、宝石1时，按评测实际结果给出该手牌形状的伤害估计、样本量、安全率及直接魔道的“异系数-1”。这是一张随策略更新的蒙特卡洛表，不是最优伤害公式，也不是绝对安全的承诺；缺少样本返回空，少于30个标注不足。五系真实牌数为水28、风27、火/雷/地各26，因此排序表是对真实系别组合的平均；决策网络仍保留具体属性。完整游戏还需考虑治疗、手限、目标防护、待处理伤害等，不应直接用这个七参数表替代所有场景。

## 单一贤者策略、中毒整回合与士气预算（2026-11-12）

用户要求停止原贤者整局分支，改为同一份贤者网络连续处理“中毒反弹→正常行动→回合结束”。原 `specialists-standard-20261112` 在当前批次后暂停，模型和优化器保留；旧 `sage-self-codex-20261112` 同样保存后暂停。新贤者从反弹专项开发最佳第1080轮继续，完整保留策略及独立价值网络权重，扩展预算输入；新阶段重新建立优化器，不平均或拼接两个旧模型。旧整局贤者不再更新。

新入口 `sage-poison-turn-v1`：贤者随机5手、2治疗、2宝石，状态区登记一张真实中毒；一个敌人满手，其他四席空手，其他英雄技能禁用。沿用引擎的行动阶段开始前中毒时点，中毒1法伤不抵扣，若有合法同系牌则进入初次反弹；后续响应恢复真实可选规则，所有合法目标开放。之后整回合行动、费用、治疗、目标、额外行动和结束由同一策略决定。其他座位使用冻结v1.5规则策略响应，不是固定放弃响应。通过完整真实结算，统计整回合敌方实际士气下降，攻击/法术/其他合法来源均计入，不以伤害量冒充士气。

用户补充允许有收益的换血，但希望实战根据局势取舍。因此单一策略输入 `objective=enemyMoraleLoss`、`maxOwnMoraleLoss`、`ownMoraleLossSoFar`，同一网络分别练0/1/2/3点自损预算。预算是任务条件，不是一定要支付的费用，不改变真实合法操作。超预算或己方战败回报-1；预算内回报为敌方实际士气损失/15。记录实际双方士气损失、预算达标率、零自损率；不把“预算内”误报为“己方未掉士气”。这一步还不是完整实战的预算选择器，也不是已经学好的两项士气预测头。

当前仍以双方初始15士气、上述固定入口训练。不同预算使用相同来源种子配对评测，按来源种子分组隔离价值验证。每轮512次，75%新场景、25%旧两异自伤练习，全部更新同一套参数；每10轮分别评测512次新场景（128种子×4预算）及512次旧场景。旧f表不能与新的5手中毒表混在一起；新报告中的“直接魔道”基准为空，因为初始中毒和整回合自由操作改变了比较范围。奖励不提供每次反弹、提炼或用治疗奖金。
