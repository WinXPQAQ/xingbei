# 本轮继续训练退化：证据与假说

当前4174按用户要求切回B组，并登记AI 1.6.0-preview.1（新评分、原网络、0次本轮训练更新）。不把C组改名，不恢复训练。

## 已有证据

三组配对对战：B对A 49.60%，C对B 46.43%，C对A 45.93%；细节和区间见ai-hero-foundation-attribution.md。B与A没有测出明显差异，C相对B的95%区间43.15%–49.70%支持本轮后续更新出现退化。没有确定具体是哪些动作或技能导致。

训练来源：hero-foundation-211/metrics.jsonl，共192批×24局=4608局，351747条用于更新的决策，0截断。前24/后24批的统计：

| 指标 | 前24批 | 后24批 |
| --- | --- | --- |
| 训练采样选择与基础规则一致率 | 84.98% | 77.32% |
| 每批平均近似KL | 0.000441 | 0.000573 |

这些是不同训练局面上的描述统计，不能视为配对评测或固定局面行为漂移。全程最大单批近似KL约0.00142，没有非有限损失或数值崩溃证据。单批KL小不等于192批相对初始策略的累计漂移小。

## 按代码应优先检验的原因

1. **陪练目标不一致。** schedule.py每24局16局全队对纯规则v1.5、4局自博弈、4局混合队伍；没有旧混合1.5.1或固定B组陪练。采样训练胜率上升而对旧网络评测下降，与针对窄陪练改进但泛化退化的解释相容；还不能单凭这一点确认过拟合。
2. **终局信用分配的高方差。** 每批只有24个完整对局的结果，却产生大量同局相关决策记录。train.py把相同团队终局±1回报赋给每个该队模型决策，优势为回报减旧价值估计，没有优势归一化，决策多的长局对更新占比更大。算法并非将每一步都判作正确，但有限样本容易把胜负噪声归给并非关键的动作。不能把351747条决策当作独立的351747个胜负样本。
3. **缺少对继承策略的长期约束。** PPO比率裁剪只约束每批采样策略附近的更新；没有相对初始B网络的KL锚点，也没有固定旧网络的行为蒸馏损失。继承初始权重不保证保留原本能力，192批小变化可能累计。基础规则95%的logit先验不是对旧网络的保真约束。
4. **采样训练与greedy部署不同。** rollout按temperature=1.3采样；服务和评测按最大分数选动作。增大随机策略的平均回报不保证每个局面的第一名候选更好。不能把采样训练胜率作为部署胜率。
5. **初始价值网络、优化器及训练长度。** 换基础评分后旧价值预测未必适配新状态分布；这轮Adam重新初始化，旧动量未继承。上述MSE没有呈现明确改善，但它是变化数据上的训练统计，不能证明价值网络失效。固定192批缺少中途保优/回退机制，也没有证明学习率1e-4在该起点合适。当前证据不足以断言是学习率过高或具体某一批开始退化。

优先方案是保留B作为固定参照和恢复点，引入旧网络陪练、增大独立对局批量、限制相对B的累计漂移，使用小步开发评测和独立最终确认。终局胜负奖励继续保留，不必因此添加命中/提炼等中间奖励。上面是下一轮设计建议，本次没有启动任何新训练；也不能把多项一起修改后的胜率提升归因于某一项。
