# 英雄策略经验的接入

2026-11-05，当前规则AI标识 `AI 1.17.0-preview.3`，首批为 `preview.2`。这是规则教师与玩法估值的更新，没有据此宣称网络变强，也没有启动新一轮长期训练。preview名称用于识别源码快照；这些版本共用正在演进的英雄模块，重现旧行为需要对应Git提交，不能仅切换旧preview名称。

## 经验如何进入AI

“白板”描述当前局面：技能条件、费用或手牌不支持发动时，回到普通攻击、法术、买合、提炼的收益比较，不把某位英雄永久归为白板。“卡法”作为攻击机会损失处理，影响留牌、摸牌和费用选择，不通过偷偷补攻击牌解决。

本批将经验放在英雄自己的 `src/heroes/<英雄>/ai.js` 及风剑牌序规划中。共用模块仅负责调用估值、团队资源机会成本与选择上下文。经验属于可调整的启发式，不是合法性条件、网络奖励或长期强制模仿目标。

例如“地打低手，再点满手”不会变成指定阵容或目标的硬条件；AI比较当前攻击分支、额外法伤与费用。没有新增“某个例子必须这样出牌”的策略测试。水影的独立弃法与潜行摸牌顺序是用户明确说明的规则，单独修正并保留必要规则检查。

## 公共提炼原则

- 规则教师通常比较两颗提炼，普通单颗有额外机会成本；风剑在补一颗确实能准备三刀时豁免这一扣分。引擎与网络的合法候选不因策略偏好被删掉。
- 用水晶或可用任意能量的英雄，给拿宝石计入队友需求的机会成本；缺宝石的宝石英雄越多，竞争成本越高。没有水晶时仍可比较拿宝石的实际用途。
- 已明确偏好宝石的英雄，对额外无用途水晶大幅降分。暗杀者、精灵射手保留一颗水晶的用途估计，多拿则降分；这不是能量区规则上限。
- 本批新增英雄声明加上已有明确的水晶拒绝偏好，以及原六英雄的能量用途估计。未声明的其他英雄不凭名字猜能量类型；后续补英雄策略时继续完善。不会声称72英雄的资源用途已经全部优化。
- 合杯、战绩存量、当前能量、费用、手牌与士气继续参与原有估值，不能仅凭“英雄没有宝石”压过立即获胜的动作。
- 若规则教师的偏好过滤排除了所有动作，回到引擎原有合法动作集合中选择，不能把“不推荐”当成“无法行动”；真正没有合法动作仍保留异常处理。

## 本批九位英雄

| 英雄 | 已接入的判断 |
| --- | --- |
| 暗杀者 | 留住前几张攻击与有用途的水，减少法术拥堵；缺宝石提高提炼意愿，偏好两红，其次红蓝。比较潜行加不可应战攻击与普通行动，模拟先摸牌、后进入潜行并降低手限。买合仍可用，但拥堵的法术手有额外成本。 |
| 风之剑圣 | 独立规划到第三刀的牌序、额外行动队列与能量，优先准备可完成的三刀，普通两刀组合降低权重。牌序不包含未来目标，每次真实攻击重新选目标；无三刀时退回普通行动估值。 |
| 嫉妒少女 | 保持已有技能与留牌估值，只补水晶优先声明。没有额外写死职业打法，细节留给训练。 |
| 剑之子 | 留攻击以准备三刀，评估誓言翻牌、变身后加伤及额外回合；变身本身给予能量，所以不无条件囤能。队友合杯获得小幅机会加分，不能当成保证变身。 |
| 魔弓EX | 从训练阵容排除。规则AI直接复用神箭手，只有不可应战属性及相应留牌偏好适配为风；真实牌属性、封印及其他英雄互动不变。 |
| 神箭手 | 狙击储能价值按补到5张后的实际空位、爆牌、士气与队友缺牌估计；提炼不再只看自己有无攻击。精准、雷与普通刀根据命中分支比较产红收益，已有贯穿射击仍比较弃法费用与法伤。 |
| 剑之魔女 | 给手牌补给增加公开价值，所有使用当前估值器的攻击者也会考虑给她送牌的收益；满手时仍正常计算爆牌压力。缺牌时买合相对提炼更有吸引力，不禁止攻击她。 |
| 精灵射手 | 比较法术/祝福费用，以及火加伤、雷不可应战、风额外攻击、水治疗、地法伤；祝福作为攻击牌使用和作为费用分别计价，清空祝福的2法伤也参与估计。手牌不减少的路线不会获得虚假的减压收益。 |
| 猎巫人 | 狩魔刺先考虑捕获目标与盖牌容量，再估计命中剥离给队友/自己减压，避免第四张盖牌挤掉更有用的剥离。灌银比较替换摸牌、交牌质量和自身治疗；偷袭把两张盖牌按法术数量与是否同系归为最多六类，比较额外攻击/法伤和费用。 |

剑之子的现有真实规则是：变身强化回合所有攻击加1伤，风剑第三次主动攻击强中。不是三次攻击全部强中。本批没有改变该规则。

## 水影规则修正

潜行时，“明弃水系牌”和“额外明弃一张法术”是独立可选部分。没有水牌或选择弃0张水，也可以询问并执行后者。基础水影不获得额外弃法。

潜行技能依次支付宝石、选择摸0或1、结算摸牌及基础水影，然后进入潜行、降低手牌上限。不能让这次进入潜行前的摸牌提前享受潜行水影。规则估值使用相同先后关系，未知摸牌仍不假定为攻击牌。

## 第二批：游击士、格斗家、剑帝

| 英雄 | 经验如何进入比较 |
| --- | --- |
| 游击士 | 同一次主动攻击比较不消耗子弹和各合法子弹效果。雷估计为不可应战，仍保留圣光与圣盾；光暗比较五种解释，通常能从雷获益，但不强制当雷。把命中后的同系二重剑影、风追加行动与实际剩余攻击牌一起估值，最多估计两次续攻，不预先锁定未来目标。 |
| 格斗家 | 比较普通、蓄力和气绝三条攻击分支；一般给低斗气更稳定的资源价值。敌方手牌压力、治疗及自身承伤空间决定准备百式的额外价值，启动再比较开百式与保留斗气。念弹计入对方是否有治疗及反伤，已进入百式后保留锁定目标限制。资源充裕且自身无能量时小幅提高提炼意愿，已有储备后不重复给奖励。 |
| 剑帝 | 提炼计入后续不屈、剑气与剑魂用途。未命中真实增加估计的剑气和剑魂，命中先比较对原目标之外角色使用剑气斩，再结算原刀；因此低手容易命中和高压力旁目标能形成组合收益。魂按当前能量奇偶开放，天使与恶魔都可不发动，恶魔额外计入小幅保留成本。不屈按非伤害摸牌、剑气上限与可见后续攻击比较。 |

这些都是有限、可调整的规则教师估值。没有把圣女、魔法少女等示例写成百式目标白名单，也没有将所有满手角色视为适合锁定。当前公开数量和治疗只是长线跑牌能力的粗略代理，复杂阵容仍需要后续训练。兽灵、女仆长本批不改策略。

### 先攻击/伤害，后自伤

- 气绝崩击宣告时移除斗气并禁止应战；这次攻击命中并结算伤害，或者未命中（含圣光、圣盾）后，再按剩余斗气自伤。没有改动其他攻击的全局时点。
- 苍炎法典、黑暗诅咒先目标法伤、后自身法伤。两者原本已按这一顺序执行；黑暗诅咒增加显式胜负保护，与公共结算停止机制一致。
- 用户再次确认：若先对目标造成伤害时已经获胜，立即结束，后续自伤不执行。不存在先胜之后自伤导致改判或平局。
- 规则教师的局部推演同样在终局停止。气绝、蓄力、剑气和魂等通过英雄自己的时点钩子修改观测副本，不执行真实规则或读取未知牌面。

## 与分层网络的关系

沿用[分层决策接口](ai-decision-hierarchy.md)。这些启发式首先改善规则教师、陪练和可解释的行动比较；结构化共享策略网络仍自行选择合法动作，只接受终局团队胜负奖励。

新的采集、规则陪练及开发评测从训练目录的固定源码快照读取统一的规则策略标识，不再分别硬编码不同教师。旧数据恢复会检查教师标识、阵容和规则版本；历史报告仍按原对手解释，不混作新版强度数据。

注册表仍有72英雄、页面仍可选择魔弓EX，训练与全英雄开发评测抽样为71位。同局不重复，红蓝蓝红红蓝不变，每71局各英雄在每个座位各出现一次；旧残局中含魔弓EX的来源不进入新课程。完整词表仍保留注册角色声明。

网络目前是共享模型，没有单独的神箭手模型可直接拿给魔弓EX。规则策略已经复用；学习模型尚未启用未经验证的角色/属性伪装。若继续做迁移，应编码“哪类攻击不可应战”等机制，再验证魔弓EX表现，不能全局互换风雷而破坏其他技能语义。

## 局限与验证

仍是公开信息下的有限估值：队友的缺牌需求主要由公开手牌数量、上限与能力估计；不知道对手能否响应，不把示例牌序当成必然发生。风剑牌序不模拟未来被应战后的全部手牌变化，下一刀会读取真实状态重算。精灵和猎巫只作有限局部推演，复杂跨英雄连锁仍可能估值不足。

保留核心规则和隐私、合法选择、牌实例守恒等通用检查，不新增固定打法测试。首批148项核心规则、14项AI接口及训练协议原有3项检查通过；12局教师采集覆盖71个训练英雄，混合阵容短跑未出现非法选择。每71局各座位均衡与新陪练标识已核对。

第二批再次通过148项核心规则和14项AI接口检查。既有格斗检查改为攻击/自伤顺序、未命中和致胜停止；既有苍炎检查补目标先伤及终局停止，黑暗诅咒沿用已有检查，没有增加测试条目。最终`preview.3`分层教师完整对局使用游击士、格斗家、剑帝、祈祷师、苍炎魔女、神箭手，种子731105203：39回合、260个子决策正常结束，未截断、无规则异常，现场摘要在`artifacts/ai/hero-strategy-preview3/smoke.json`。这不是固定打法断言或强度评测；两批均未做新胜率对照。
