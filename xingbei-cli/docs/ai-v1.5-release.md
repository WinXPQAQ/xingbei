# AI v1.5：基本打法与完整计划

v1.5是已验收`experimental/plans-4`的稳定别名。CLI、Web及引擎共用默认指向v1.5；五个策略文件逐字复制自冻结提交`a0e9baaf622432935de4c01dbf996f738ff7801b`至`src/ai/v1.5-plans4/`。发布不调权、不改变搜索或响应行为；v1.4及全部旧稳定/实验版本继续保留。本轮未训练模型，未执行服务器部署。

## 改动

- 封印师将圣盾、魔弹和法术激荡的免费追加刀作为完整计划，计算跑牌、曝光、回应和实际资源变化。圣盾被消耗是防护兑现，没有自动扣成额外净损失或给予固定奖励。
- 按英雄可兑现用途区分宝石与水晶，精确分配共享资源机会成本，计入两次可用能量对提炼行动的分摊，同时保留容量、已有资源、队友需求和无法兑现的例外。
- 水之神力完整比较水牌成本、赠牌、治疗、溢出和封印师接收魔弹的用途；仅使用赠牌者合法可见的信息。
- 所有行动使用共同的有界未来风险口径，比较等待、眼前败局和反杀机会。已确认终局与未知回应条件分支分开；每个首动作最多64次扩展，不盲目扩大整棵树。
- 补齐天使普通圣盾/墙的自由目标羁绊、保护资源与免费治疗的单调性、风之洁净的曝光结算顺序，以及神官契约和实际行动费用预留。
- 公共历史记录谁出牌打谁、回应转向/抵消、命中、技能响应、效果、治疗、资源与士气结算，供解释和决策使用；不共享队友暗牌或未来牌序。地系封印统一显示“地之封印”。

[逐项改动、正反例及局限](ai-v1.5-plans4-review.md)和[原五例的新旧对照](ai-v1.5-plans4-cases.md)保留真实完整动作链。原69个合法选项在v1.4下精确重现，不用后来赢输证明单步最优，也不强制拟合用户未要求的具体排序。

## 验收

按[预登记的新配对协议](ai-v1.5-paired-validation-proposal.md)完成25920局，两套独立实现结果一致，零截断、完整清单、四分片正常退出，155个冻结文件哈希核验通过。

|比较|结果|
|---|---|
|全队对v1.4|3914/5760胜，67.95%；总体及四阵容下界全部过门|
|同flow队友、只替换一席|候选31.81%，控制25.72%；差+6.09pp，下界+3.61pp|
|同reserve队友、只替换一席|候选12.99%，控制11.62%；差+1.37pp，下界−0.28pp|
|历史v1.3/v1.2/v1.0|69.27% / 74.48% / 85.83%，均过原点值门|

以上下界为七端点统一单侧99.3%整种子簇bootstrap，名义家族覆盖约95.1%。reserve只达到预定非劣及观测差非负门，不能称显著优越。两种压力队友下绝对胜率仍低，不表示能带任意弱队友达到50%。

18格性能全部通过：总体p95 **27.50ms**、最长 **86.82ms**，最大中位比 **1.7604**、p95比 **1.7779**（相对门2倍）。这是固定公开决策截面的耗时，不是任意设备端到端延迟保证。

## 保留的失败与限制

第一、第二候选因真实规则/资源反例停止；第三候选原17280局虽主比较通过，但混合队友绝对胜率未达当时45%门，仍为FAIL。原混合设计缺少同队友控制，混淆了单席变化和队友强度；本次重新预登记不同测量对象、使用全新种子，没有改判旧失败或放宽原实验结论。所有失败数据、审查、性能超预算记录及修复后的等价证据均保留。

未知牌、魔弹接力、长期能量用途和多回合协作仍是近似；没有校准成真实胜率，不证明真人强度、任意阵容最优或完整博弈解。免费追加和能量分配也不是所有局面都应无条件选择。
