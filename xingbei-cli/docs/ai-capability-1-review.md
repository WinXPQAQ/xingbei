审查日期：2026-10-19。基线提交：`abc939877a12ecedd60b3d7e97eb5f7b4ae2d195`。本审查仅新增此文档，未修改源码、测试、工具、历史证据或提交状态。

## 结论与改动边界

在当前已实现六英雄范围内，未发现阻止该实验候选提交的正确性问题。候选只修正闪光陷阱、精准射击、天使之墙三个每项 2 分的保牌能力加值条件；没有调整盾权重、其他评分权重或默认版本，不构成强度提升或发布结论。

逐文件检查确认：`economy-capability1/planner.js` 与冻结 economy4 文件逐字节相同；新 model 仅增加公共能力快照、将三项无条件牌面标签加值改为能力检查。新 index 仅更改实验身份并复用冻结 trace 工具；版本注册只增加 `experimental/economy-capability-1`。原有策略目录和 `src/ai.js` 无改动，生产默认仍是 v1.3/economy4。能力判断未借用未来接牌人的技能，没有为神官凭空创造精准或陷阱能力。

## 能力条件与真实引擎

- 所有三项必须由本人 `getSkills()` 实际提供，且保留手牌带对应技能标记。英雄名称本身不授予能力；关闭英雄规则或实际移除技能后不加值。
- 精准射击还要求标记所在牌是攻击牌，并存在敌对目标，与真实攻击声明触发一致。
- 闪光陷阱允许指定任意玩家，包括自己和队友；因此其目标存在条件无需错误收窄为敌方。
- 天使之墙要求至少一个当前未持有圣盾的目标，可为任意阵营。所有人都已有圣盾时不加值；模拟分支移除圣盾后恢复加值。保留标记牌被消费后也不再加值。

这些是下一普通行动选项的保牌估值，不是宣称此刻额外行动或响应阶段都能直接发动。真实引擎仍负责行动阶段、费用、目标和结算校验。

新增 `skillIds` 从现有分离观测的公共技能列表建立，没有加入隐藏手牌或未来牌库。数组冻结，模型 clone 共享不可变数组，手牌和效果分支仍独立复制；测试在克隆中修改手牌类型/移除手牌，不污染原分支。隐私反事实测试改变他人暗牌及未来牌序后，新候选排名和 trace 不变，trace 可重放。

能力快照有明确边界：技能列表在一次决策建模时固定，若未来加入“挂载牌授予这三项能力”，模拟中移除该挂载牌不会自动撤销快照能力。当前六英雄的这三项是固有技能，未涉及该问题；不能把本修复描述为所有未来动态技能获得/失去路径均已正确建模。
