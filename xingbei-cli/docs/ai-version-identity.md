# AI 整体版本编号建议

一个公开AI版本代表整套决策程序，而不只是神经网络。身份包含：游戏规则引擎源码、基础评分策略源码、网络权重、观测编码、推理方式（例如greedy）、最终选牌修正规则。每个发布版本均应固定这些身份，不允许同名覆盖其中任一项。应用界面的0.6.3是另一层应用版本。

建议沿用三段式 `AI 主版本.评分规则版.网络迭代版`：

- 主版本：决策接口、观测编码或整体架构不兼容改变。
- 评分规则版：基础评分/推演/最终选牌修正规则改变；网络迭代从0起。
- 网络迭代版：同一评分规则下更换网络权重。
- 未晋级的组合加`-preview.1`等后缀；正式版删除候选后缀也需保留原版本记录。

例如，未来可用AI 1.6.0-preview.1表示新评分加原网络（尚未训练），AI 1.6.1-preview.1表示相同评分加新训练网络。这里只说明新命名约定，并未重命名本会话已经登记或部署的AI 1.5.1、1.5.2、1.5.3-preview.1。

编号便于人阅读，完整身份应由发布清单绑定哈希，不能单凭三个数字恢复实现。游戏结算规则变化即使没有改AI权重，也要发行新的组合身份并重测；不可沿用旧胜率。候选编号不表示更强，必须独立保留评测结果和晋级状态。

当前三组对照采用A/B/C标签，避免将未晋级的对照模型冒充正式发布：A=旧评分+原网络，B=新评分+原网络，C=新评分+再训练网络。三组使用相同terminal-v1游戏结算规则、相同观测编码和greedy推理，没有额外应战后处理。B使用真实initial.pt，其网络张量已逐项确认与A一致。
