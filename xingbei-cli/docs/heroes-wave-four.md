# 第四批英雄：0.9.0 / AI 1.9.0-preview.1

实现冒险家、格斗家、勇者、红莲骑士、魔枪、吟游诗人。仅使用十周年包 `character/shiZhouNian.js`，不实现破晓/龙族扩角色。每位英雄的规则、AI和观测声明在 `src/heroes/<英文名>/`。

## 本批裁定

- 格斗家气绝崩击在攻击前①移除斗气后立即自伤，不沿用旧代码的攻击结束后自伤。
- 魔枪暗之障壁整组全为法术牌，或整组全为雷系牌，不能任意混合。该技能通过弃牌腾空手牌，不直接减少伤害数值。
- 冒险者天堂允许自身零能量发动；有能量才移除1。宝石可支付水晶费用，沿用引擎规则。
- 吟游诗人使用用户提供的新规则：对第二个不同敌方角色开始造成法伤③时即可沉沦协奏曲；永恒囚徒形态承受法伤−1，目标队友发动胜利交响诗时诗人+1治疗；胜利交响诗资源分支移除任一种己方战绩星石，持有者获得1宝石。禁忌诗篇仍在乐章效果结算后执行。

## 规则边界

欺诈为虚拟攻击描述，不制造新的实体基础牌；费用明弃，随后进入共用攻击流程，支持普通应战和圣光确认。新增单次攻击结束事件供明镜止水使用，不替代攻击行动结束。

挑衅和永恒乐章各创建唯一专属实体，初始场外，移动/授予技能使用原有实体机制，不属于基础效果。挑衅允许跳过行动阶段；继续时只能主动攻击施加者，启动后再次检查。死斗的士气限制随本次伤害来源传递，不污染后续伤害。所有技能仍遵守胜利立即结束。

## 基础评分

- 冒险家保留同系组合，评估欺诈和战绩转换，天堂倾向一次交两颗。
- 格斗家偏重攻击及斗气资源；气绝与念弹计入自伤风险，已有形态提供攻击加权。
- 勇者提高火、水及法术保留价值，禁断之力按火牌加伤/法术资源判断，死斗考虑爆牌与怒气。
- 红莲保留两张法术，积累血印，杀戮盛宴比较额外攻击收益与自伤。
- 魔枪保留雷系与法术作为弃牌费用，不能使用圣光；漆黑之枪按额外伤害收益决定能量量。
- 吟游保留同系组合，以乐章及灵感循环为主；胜利交响诗可将战绩水晶转换成个人宝石。

这些是首版确定性评分，不代表强度验收。复杂连招和形态自伤的估计仍较粗，需用户试玩反馈；本批没有启动网络训练。网络仅补注册新英雄和相对玩家引用类型。
