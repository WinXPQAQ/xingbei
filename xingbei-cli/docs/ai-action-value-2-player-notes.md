# 如何理解负分与持牌期权

普通行动必须做。评分中的0只是“计划前后模型估值相同”，不是允许放弃；只有规则允许的额外行动和可选响应可以放弃。新候选的五个自然全负实例见[案例说明](ai-action-value-2-negative-cases.md)，它们来自固定顺序的独立对局，不是把旧案例换一套分数。

## 原例1的能量−7不是花掉一颗宝石

旧版风剑出地刀打0号时，模型把能量价值从7.5降到0.5，原因是手中攻击牌由两张变成一张，失去了“至少两张攻击牌才有+7”的持有奖励。每个搜索分支里那颗宝石仍然存在；开关追加攻击搜索都如此。不能解释为引擎强制发动剑影，也不能说真实消耗了7点资源。

新候选把首份风剑能量储备计为3，后续每份增加0.5，避免这个突然跌落。剑影仍是可选支付，搜索只有认为支付后的后续收益更好才选择它。这个储备数仍是启发式估计，不是宝石的客观价格。

风剑无能量也可以利用疾风技与风怒追击连出三刀。原例地牌的烈风技（stormArt）是针对圣盾的攻击能力，不是免费追加行动的疾风技（galeArt）；不能把两者混为一谈。保留连刀机会的评分也不等于保证未来能执行三刀。

## 采购的牌不是只增加负担，也不是保证防住下一刀

旧模型把未知新牌按统一持牌值和总手数负担计算，未把它们可能带来的防御或连刀准备纳入。实验1曾扩大未知牌的持有估值，但完整确认失败，因此没有采用。当前候选保留原通用未知牌估值，只用固定公开牌表估计补牌后的防御概率、风剑连刀准备及相关法术积压，不读取真实未来牌序，也不会让未知牌直接进入当前可执行攻击搜索。

这个先验只扣观察者决策开始时已知的本人手牌，不是真实剩余牌库的精确后验。满手采购后可能因后续伤害爆牌，但“特意不响应后确实死亡”只证明存在风险，不能证明采购在所有响应下必输。当前风险仍是公开场面的有限近似，不是完整下一轮博弈。

原例1当前候选仍将采购排得较低：采购−9.7406，地刀打0号−1.3631。采购分项为星石+10、合成路线准备+4.4829、本人持牌与积压−4.2588、来袭风险−19.9647；新牌带来的后续攻击、产石及多回合收益没有充分展开。这仍与专家参考偏好存在分歧，不能把模型排序定义为规则正确答案，也没有为了贴合该例继续改权重。

## 神官水牌的+4不是发动时应另返的奖励

旧例4水神力先支付水刀、再送火刀，手牌估值合计下降10；其中水神持有期权+4消失了一次，真实交牌与双方治疗效果另有计入。它不是被扣了两次，也不应为了让发动看起来有利而机械返还4分。

另一方面，固定持有奖励可能使模型偏好继续留牌，而低估现在兑现技能的机会。这种有限搜索带来的保留偏置仍未完全解决。当前候选没有宣称神官水神期权已获得精确估值；应结合合法技能目标、交出什么牌、队友负担、治疗与胜负压力判断，而不能仅靠“评分负，所以不该发动”。

首动作和追加动作的成本收益已在案例中分开。整条计划的本人手牌扣分可能包含追加攻击的耗牌，不能全算到首张法术头上。随后整局获胜或失败也不能单独证明当时选择最优。
