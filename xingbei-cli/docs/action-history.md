# 行动记录（v0.6.2）

六位英雄的技能记录包含发动者、技能名，以及对应的目标、费用和实际结果。角色名后保留座位名，便于区分阵营与同名角色。公共操作由Game统一记录；技能自己的增伤、强制命中、响应限制、分支选择等在技能结算处记录，不通过解析日志执行规则。

## 可见性

| 信息 | 正常游玩及终端默认 | 测试／观战游玩 |
| --- | --- | --- |
| 使用、展示、明弃、附加及移除的公开牌 | 属性、命格、类型、牌名 | 同左 |
| 摸牌、交牌、爆牌暗弃、技能暗弃、盖牌明弃 | 数量及参与角色 | 额外显示每张牌的属性、命格、类型、牌名 |
| 治疗、能量、士气 | 实际变化及必要的上限说明 | 同左 |

例如正常局记录“神官（红一）将一张牌交给了神箭手（红二）”；测试局记录“神官（红一）将一张牌（[风][技]攻击【风神斩】）交给了神箭手（红二）”。牌名以实际卡牌为准。

引擎构造选项`revealHiddenLogs`默认false，网页版只在所选模式为测试或观战时打开。它与服务器`TEST_MODE`版本标记独立；重开正常局会创建默认隐藏记录的新Game。牌的日志文字在转移前取得当前属性与命格，已经写入的记录不会随实体之后移动而变化。该开关不修改弃牌的`discardVisibility`、公开事件、AI信息范围或暗弃动画。

## 命格图标及验证

测试和观战的26px手牌缩略图在右上角添加11px命格文字，复用当前牌的`getTraits`，兼容空命格与多个命格。图标标题仍保留完整牌面说明。正常模式不显示其他玩家手牌。

74项Node测试通过，新增3项分别覆盖水之神力完整日志与隐私、所有弃牌可见性及规则结果一致、被动增伤／费用／效果移动。1440×900桌面与390×844触屏的模式97项和响应155项，共252项浏览器检查通过，控制台／素材错误0；截图与结果位于`artifacts/logs/modes/`、`artifacts/logs/responses/`。浏览器验证包括命格位置、测试暗弃明细、正常摸牌隐私、观战公开记录及原响应确认流程；并非六英雄每条日志都做了浏览器逐条验收。

本次只调整记录和测试界面的命格标记，不扩大原版整体视觉还原的验收范围。截图采集时版本标记仍为0.6.1，完成后版本更新为0.6.2。
