# economy-3 渐进候选验收

冻结源码：`573890e24e892fe7e3f15790e4b66828f386df32`。当前生产仍为v1.2，候选注册名experimental/economy-3；未经父线程验收不发布。

## 本轮修正与边界

对所有src可达choosePlayer调用核查，现有仅两类：天使羁绊（angelBond）给予1治疗；神圣契约（holyContract）转移可变数量治疗。原通用选人统一加1治疗存在语义错配。本轮给天使羁绊增加明确skillId，只对此请求使用+1治疗状态评价；契约及未知请求明确退回旧合法辅助。没有把未知效果伪装成治疗收益。

候选并非所有英雄决策都已统一评价。契约是否发动及数量、神之庇护/圣剑数量，以及血刃、血腥咆哮、暴风术、神圣启示等部分技能开关仍沿用旧辅助。普通攻击/圣光/魔弹响应、手牌弃置/赠牌及治疗采用新状态比较；魔弹尾部、反击后续和少数英雄联动仍为近似。契约选人保留原启发式，未声称该路径已最优。

为减少延迟，分支复制改为显式复制可变玩家、能量、手牌/已知牌/效果、团队和回合；同一观测内的深冻结traits、历史及信念可共享。独立测试递归确认共享对象只读、可变字段互不影响；六座位完整行动评分与冻结economy-2相同。此性能优化不更改权重、搜索128/root限制或束宽2。

原economy-2四个策略文件逐字节保存在v1.3-economy2，旧别名不覆盖。由于playerChoice行为有变化，82001–82006旧验收降为开发证据；本轮不用它充当新holdout。

## 新留出协议

主92001–92030共30个全新种子簇，四阵容×六先手×两颜色，每对1440局：候选对v1.2、候选对v1.0、v1.2对v1.2、v1.2对v1.0。后两项提供相同英雄归属、种子、先手、颜色下的旧默认对照。

风格留出94001–94006另六簇，对flow/reserve分别运行候选与v1.2，每对288局。合计6912局，主与风格簇不混池。旧训练及82001批次不进入新统计。

完整门槛在release/protocol.json，开跑前冻结：总体对v1.2胜率≥53%且95%簇下界>50%，相对同条件v1.2自对抗改善≥3个百分点且下界>0；对v1.0胜率下界>50%，相对旧默认对v1.0差值下界>−5个百分点；四阵容各自相对自对抗控制的95%差值下界>−5个百分点；两风格对手也要求胜率≥50%及相对旧默认差值下界>−5个百分点；每对截断≤1%。

按同阵容/种子/先手/颜色配对并核对heroIds，先求整种子差值均值，再10000次bootstrap。每阵容同时报告边际95%和Bonferroni98.75%区间；总体passed只对应协议边际门，四组同时非劣单列。区间跨过−5个百分点表示证据不足，不能用“不显著”声称没有有意义的退化。
