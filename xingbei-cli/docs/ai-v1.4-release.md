# AI v1.4：定向修错发布

v1.4 是已验收 `experimental/targeted-fixes-1` 的稳定别名，CLI、Web和引擎自动决策共用默认切至v1.4。策略目录仍为冻结源码 `0ada54a7d978d29164c35164d56717f54728b153` 中的 `src/ai/targeted-fixes1/`；发布只增加别名和切默认，不重调权重、不改变搜索或响应行为。v1.0/v1.1/v1.2/v1.3及实验入口继续保留。AI版本独立于应用版本。

## 实际修复

- 牌标技能估值只计本人真实拥有、且当前公开条件满足的技能，避免把别人角色的技能算作本人的持牌收益。
- 去除观察者风剑“两张攻击牌”门槛制造的虚假−7能量估值落差。首份能量储备估值3，后续每份0.5；实际剑影支付仍依规则结算，非观察者公式不变。
- 公开四杯且至少三共享星石时，合法治疗足以把手数保在三张的预测与实际治疗选择共用判断，仍遵守神官单次1点上限。这是当前资源可行性，不保证对手如此响应或下一席必胜。
- 解释阶段复用同次决策不变的根状态分项；180截面3990计划与原算法的完整排序、分值和解释哈希一致。

普通行动不得跳过、无法通常行动时按规则换牌等共同引擎修复此前已发布到main `67ab4de`，所有旧版也使用相同规则适配。不能将历史非法普通pass当作较弱比较基线。原28800局等错误规则证据整体失效、原始记录保留；本次采用重新登记的独立样本。

## 固定证据

[完整结果](ai-targeted-fixes-1-results.md)保留协议、全部阵容/先手/颜色结果及局限。25920局：对v1.3为5977/5543（51.88%）、对v1.2为934/506（64.86%）、对v1.0为1152/288（80.00%），配对自博弈5760/5760；全部零截断，无运行错误，主比较发生1次合法换牌。

主比较240种子，总体和四阵容相对同配置自博弈的Bonferroni单侧下界分别为+0.9635、−2.4653、+2.6736、−1.5625、+0.1389个百分点，均≥预登记−5pp。不能声称每组都改善或真人更强。独立性能矩阵18格全过，最大中位比1.02933×、最大p95比1.02948×；仅是公开回放评分耗时，不是端到端延迟保证。

[新自然全负案例](ai-targeted-fixes-1-negative-cases.md)来自最终冻结版本的新种子：15场自然对局、301普通决策、14全负事件，按每英雄首次取5例共69合法选项；独立完整重放一致，负分仍执行合法动作。分数不是胜率，零分不是普通pass选项，随后整局结果不证明动作最优。

## 未解决反馈

风剑购买后的多回合攻击/产石及连刀潜力仍未完整展开；未知补牌仍采用通用2.6估值；团队共享资源长期分配和神官水牌持有期权偏置仍有近似。没有引入此前失败候选的广泛路线/未知牌价值重调，也没有按阵容切回旧策略。[原例诊断](ai-targeted-fixes-1-diagnosis.md)区分实际修复和保留问题。
