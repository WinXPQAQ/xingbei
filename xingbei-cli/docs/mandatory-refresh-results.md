# 普通必行动与无法行动换牌纠错（二）

规则候选，待父线程验收，未发布。生产AI仍v1.3，历史策略源码冻结；能力留牌实验维持独立入口。

用户明确：提炼是一项行动，但不计入“无法行动”判定。当前阶段无合法非提炼行动才能申请展示弃置全手并等量重摸；换牌不是行动，不结束回合，可重复申请。三圣光风剑仍可购买/合成；四圣光可选择提炼或换牌。启动后特殊行动限制保留。没有增加新角色或启动框架。

引擎拒绝普通未行动结束；换牌保留回合状态，不触发特殊行动奖励，但正常结算公开曝光/封印伤害。CLI/Web提供申请换牌选项并保留提炼；所有自动驱动循环持续至真实行动完成。共有适配层遇到无法行动先换牌，再重新询问冻结策略，避免执行旧搜索中“换牌结束行动”的模型。该确定性默认可能错过更优提炼，但不违反规则；人类可任选。额外行动只能按规则放弃，不能借换牌套利。

当前没有合法行动且零手牌的阶段，如未来角色限制购买且无牌可换，明确抛规则状态错误；未虚构补牌、伤害或pass。当前六英雄正常开局空手可购买，因此本轮不实现未来角色方案。
