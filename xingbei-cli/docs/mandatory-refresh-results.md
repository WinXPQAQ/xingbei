# 普通必行动与无法行动换牌纠错（二）

规则候选，待父线程验收，未发布。生产AI仍v1.3，历史策略源码冻结；能力留牌实验维持独立入口。

用户明确：提炼是一项行动，但不计入“无法行动”判定。当前阶段无合法非提炼行动才能申请展示弃置全手并等量重摸；换牌不是行动，不结束回合，可重复申请。三圣光风剑仍可购买/合成；四圣光可选择提炼或换牌。启动后特殊行动限制保留。没有增加新角色或启动框架。

引擎拒绝普通未行动结束；换牌保留回合状态，不触发特殊行动奖励，但正常结算公开曝光/封印伤害。CLI/Web提供申请换牌选项并保留提炼；所有自动驱动循环持续至真实行动完成。共有适配层遇到无法行动先换牌，再重新询问冻结策略，避免执行旧搜索中“换牌结束行动”的模型。该确定性默认可能错过更优提炼，但不违反规则；人类可任选。额外行动只能按规则放弃，不能借换牌套利。

当前没有合法行动且零手牌的阶段，如未来角色限制购买且无牌可换，明确抛规则状态错误；未虚构补牌、伤害或pass。当前六英雄正常开局空手可购买，因此本轮不实现未来角色方案。

旧mandatory-action目录1728局与更早28800局均保留且失去当前规则强度证明效力，不按截断或是否出现换牌筛除。新协议artifacts/ai/mandatory-refresh/protocol.json预登记独立种子331001–331012、四阵容、六先手、双色配对，共1728局，300单人回合上限。所有截断保留。引擎/策略冻结SHA为099484fd97075fe9c63b72d8a742769fb2b8467f，1728局结果见下。

回归覆盖全负评分仍行动、普通end拒绝、强制请求、额外放弃、全部历史策略、隐私反事实、三/四圣光、反复换牌、当前阶段限制、真实神官不获启示、真实封印曝光伤害。换牌单列exchanges，不作为actions或主动关键牌消耗统计。

## 验证与运行限制

最终全量151项Node测试通过；独立审查运行149项全量和追加后的6项换牌专项。实际CLI PTY验证普通end不能离开行动提示、quit正常退出。浏览器入口smoke通过，实际人类换牌按钮连续两次通过（测试注入四圣光状态与确定牌序，非自然完整对局），无pageerror；第一次换后仍可申请，第二次获得4攻击牌，普通end仍拒绝。测试脚本与JSON在mandatory-refresh目录。

这不是完整视觉/响应验收。上一阶段完整响应脚本在基线与候选均有相同魔弹转移断言失败；本阶段未声称该既有问题修复。首次浏览器运行缺本机Chromium，安装至/tmp后复测通过；未改服务器或部署脚本。

历史原始traceDecision/replayTrace仅用于还原历史模型，可能包含普通pass或“刷新结束”的过时语义；不可直接当执行计划。正式注册choose/rank入口受到共有合法性层约束。冻结策略的强度缺陷保留，规则修复不是对其评分正确性的保证。
