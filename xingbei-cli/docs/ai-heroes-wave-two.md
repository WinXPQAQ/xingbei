# 六新英雄基础评分与体验部署

版本：应用0.7.2，确定性策略`v1.7.0-preview.3`。这不是训练出的新网络，也不继承旧混合模型的胜率。新六英雄进入专门评分，原六英雄保留v1.5的其余决策，仅在本预览版统一采用新的主动魔弹评分。历史v1.5别名和冻结源码、模型文件不改；旧预览版可由各自固定提交恢复。

## 公共评分结构

策略只获得自己的手牌和公开的角色、治疗、手牌数量、能量、效果、元素、横置形态及历史。不得读取他人牌面、暗弃或未来牌库。新状态采用白名单加入观测，而非直接传整个hero.state。

行动沿用公共局面差分估计，士气基础权重30、星杯48、星石5、治疗2.5；这些是启发式单位，不是胜率。新技能明确估算费用和效果，一般额外行动只看一次后续；元素连续法术采用下述有界规划，避免无限奖励追加行动。对手弃牌与魔弹继续响应采用公共概率近似，不假装知道其手牌。所有合法行动由引擎列出，评分不执行规则。

留牌分与行动分不是同一个尺度。普通牌沿用原基础留分，暗灭和至少一张圣光仍优先。新英雄保留加分在爆牌/明弃选牌时乘10，主动打出和技能支付时作为机会成本扣除；最终非光暗留分封顶130。圣女/元素的独有技只按本人技能识别，别人的印刷标签不享受保留加分。

| 英雄 | 留牌加分（行动机会成本尺度） | 行动与发动规则 |
| --- | --- | --- |
| 圣女 | 治疗术、治愈之光+5；水牌+3，同系已留则+1 | 使用水/圣光计入冰霜祷言的实际可增治疗；独有治疗法术考虑目标阵营和治疗上限；圣疗计入分配和一次额外攻击/法术收益。怜悯仅未横置、支付后不会耗尽预定行动费用时考虑。 |
| 圣枪 | 对面有治疗英雄时法术+3；水牌仅辉耀敌我实际增疗比较允许时+3；同系已留则+1.5 | 天枪只在目标满手、无圣盾且预计有士气损失时开；它不等于强制命中，仍可能被圣光抵消。地枪遍历合法治疗费用，以30×新增士气损失−3×治疗费用评分，无增量则选0。辉耀比较敌我所有角色实际可获得的治疗，敌方获得更多则记极低分；后续攻击计分。治疗英雄包括天使、神官、圣女、圣枪、瘟疫法师、女武神。 |
| 瘟疫法师 | 地或法术+3，同系已留则+1.5 | 法术行动计入不朽的实际增疗，基础法术另+1倾向；死亡之触排除不朽，费用和伤害共同估算。瘟疫、剧毒新星同时计入队友损失，不能只看对方伤害。提炼使用与魔法少女相同的宝石准备评分。 |
| 元素师 | 本人的五种独有技+5 | 元素点燃/陨石必须有值得执行的后续法伤，或当前直接获胜。独有技追加优先低价值普通同系牌，默认保留本人五种独有技；仅当额外1伤通过公开治疗/神之庇护后能直接获胜时允许消耗它。行动规划和实际追加共用判断，并比较不追加分支，避免明弃费用触发封印后先输。提炼首颗宝石+26，后续每颗+6，第一颗有用水晶+8；战绩恰好1宝石、至多1水晶允许单宝石例外；提炼后个人水晶超过1或无例外的单颗提炼记极低分。 |
| 魔法少女 | 法术+3 | 魔爆计入战绩宝石，另+3转换倾向；两目标按55%承受伤害/45%明弃近似，扣除自己的后续弃牌成本。目标选择仍考虑收益，不是永远优先魔爆。提炼2颗时，首颗宝石+26、后续每颗+6，无技能用途的水晶每颗−2；单颗仍−12。被魔爆要求弃牌时比较弃牌与承伤，避免为不掉士气的伤害随便交圣光。 |
| 女武神 | 法术固定+2 | 见下文。 |

三法术英雄提炼若消耗掉我方第四杯后可合第五杯的星石，额外−30，避免为蓄能阻碍直接获胜。

同系重复会降低水/地保留加分，不鼓励无限屯同一种牌。普通单颗提炼仍降低优先级。元素最多1水晶是AI偏好，不修改游戏能量规则；没有其他可行行动时仍由合法行动兜底。

## 女武神的专门规划

`src/ai/hero-wave-two/valkyrie.js`集中处理：

1. 英灵形态的价值取未来治疗与队友支援的有限收益，最高7分，不视为永久收益。
2. 主动攻击扣除失去当前形态的价值，再按公共估计的命中率加入英灵召唤收益。攻击先重置，命中后可以重新召唤；圣盾不会贡献预期入形态收益。
3. 命中时召唤比较新增士气收益、自己回合入形态收益和能量成本（水晶3.5，宝石6）。回合外只计加伤；当前已在形态不重复奖励。新增致胜士气损失强烈优先。
4. 神圣追击比较最有价值的下一刀与失去治疗的防御成本；有可用额外攻击不重复买。形态不是禁止攻击的硬条件，明显获利或斩杀可以破形态。
5. 军神威光比较免费自疗并重置与支付1至2星石治疗。优先救高手牌、低士气队友；没有有效治疗空间不花石头。消耗会使星石从至少3跌到不足3时额外扣分，已有4杯时扣24，保护第五杯。
6. 英灵召唤的追加明弃比较治疗收益与牌值，保护唯一圣光；普通法术也不会无条件弃置。有治疗空间的队友优先于自己，队友都满时才考虑自己。主动攻击预期收益也计入实际可发动的召唤加伤、入形态及弃法术治疗收益。
7. 移除女武神魔弹的固定−18/−10/−4罚分，统一采用全英雄的主动魔弹收益模型。
8. 秩序之印使用下列明确偏好；“星石”指个人能量，最高3。普通回合仍必须执行合法行动，极低评分不改变技能合法性。直接获胜的高分行动不被准备动作覆盖。

| 状态 | 秩序之印偏好 |
| --- | --- |
| 至少2牌空余，治疗和能量都未满 | 优先发动 |
| 不足2牌空余，治疗/能量均0且士气充足 | 倾向发动；当前阈值为士气≥8，预计爆牌后≥6 |
| 不足2牌空余，已有资源或士气不足 | 不倾向发动 |
| 至少2空余，治疗满、能量0 | 倾向获取第一颗能量；已有能量则不倾向 |
| 至少2空余，能量满、治疗0 | 判断手牌质量；手牌≤2或至少半手为低价值牌时考虑补牌 |
| 其他资源已足够的情况 | 不倾向发动 |

## 元素连续法术

`elemental-plan.js`只用已知手牌、公开治疗/手牌数/能量/元素做分支估计。最多5个法术行动，每次后续搜索96个节点、宽度8；只有陨石和元素点燃递归追加法术，风刃估一次后续攻击。牌和费用逐张移除，月光先付宝石再计算伤害，元素点燃不会自己补回元素，也不凭空预知未来摸牌。

可以识别“2元素＋陨石追加普通地牌→元素点燃→月光”的2+2+3，以及两张陨石分别发动后接点燃/月光的1+1+2+3。不能为了第一张陨石加1伤就默认丢掉第二张陨石。后续伤害仍需有正收益，不能只因多一个行动就发动；这是有限启发式规划，不是完整规则树搜索。

## 全英雄主动魔弹

旧评分会同时奖励降低自己的手牌负担、提高对方手牌压力及下一次爆牌风险，导致不掉士气的魔弹也可能排在攻击之前。`magic-value.js`将主动魔弹改为对这次传递实际后果的估计：士气、消耗的治疗/圣盾/能量、对方用于响应的牌，扣除本次出牌成本。不再把“让对手多摸牌”单独计为进攻收益。

最多估6次受弹，目标遵守方向与本轮已参与者，未知响应按公开牌表概率估计，魔法少女火/地转换也计入。封印师法术激荡只估剩余手牌实际可出的攻击；瘟疫法师计入行动结束实际可增加的治疗；圣女水牌的冰霜祷言先于传递加入治疗，元素吸收仅按本人的法伤分支计分。胜负已成立不再奖励后续效果。真实响应决策没有被这一主动出牌模型替换。

这是有限公开概率模型，不是已知对手手牌或完整传递结果。女武神神圣追击仍由实际行动结束决策判断，未在所有首行动预估中展开；不额外给魔弹独占的追击奖励。
