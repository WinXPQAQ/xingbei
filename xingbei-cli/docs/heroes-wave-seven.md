# 第七批英雄：0.12.0 / AI 1.12.0-preview.1

本批实现蝶舞者、战斗法师、星坠女巫、圣庭检察士、猎巫人、圣殿骑士，共42位可选。蝶舞者来自原项目十周年包，其余五位来自异端业火包。用户已确认后续排除破晓与龙族包，其他角色可以实现。

## 规则裁定与共用接口

- **朝圣可以减少灵魂链接转入的伤害。** 用户明确确认：与新版吟游诗人的永恒囚徒一起，构成目前两个可降低链接转入伤害数值的例外。链接转入仍直接从⑥开始，不重跑③至⑤与治疗。
- 毒粉在⑤先增加实际法伤；镜花水月在⑤抵御原2点法伤，再分别开启两次③的1点法伤。朝圣绑定⑥，不过滤 `soulTransfer`。
- 圣殿骑士的神之子在③替换伤害，新伤害直接从⑥处理；圣炎仍保留到替代伤害完成后重置。神威禁止的是本回合获得治疗，不是使用已有治疗；同回合多次神威累计禁止目标。
- `HEALING_OVERFLOW`记录每次获得治疗时未能加入的部分，每次事件只触发一次。神威禁止获得治疗不算溢出。裁决所的治疗独立于角色治疗，不递归触发普通治疗溢出。
- `moraleFloor`由实际规则在士气变化时处理；凋零保护敌方、圣炎保护我方。记录与动画使用实际士气变化量，胜负仍由共用引擎检查。
- 猎巫转换不改写实体牌的印刷类型。候选保留实体牌ID、`asAttack`与目标；实际结算使用虚拟攻击，最后清理原实体牌。圣光仍单独确认，转换牌以点目标为提交。
- 变长盖牌费用分步选择，候选指向具体盖牌实体，当前问题保留已选实体引用。只编码持有者可见牌面，不用唯一牌ID字符串充当类别特征。
- 恩典神授复用特殊行动路线，独立提供向队友提炼的合法选项；不覆盖普通提炼。裁决者不消耗法术行动。
- 多目标效果按当前逆时针座次顺序处理；胜负成立立即停止后续效果。盖牌展示移除不触发封印；手牌明弃/展示仍走通用公开事件。
