# 第六批英雄：0.11.0 / AI 1.11.0-preview.1

新增精灵射手、阴阳师、灵魂术士、血之巫女、月之女神、圣弓，共36位可选。来源为原项目十周年包，不引入破晓／龙族扩。每位英雄的规则、评分、观测声明分别位于自己的 `src/heroes/<英文名>/index.js`、`ai.js`、`observation.js`。

## 用户裁定与规则依据

- 血之巫女的同生共死指定自己时，仅自身手牌上限改变一次：普通形态−2、流血形态+1。修正旧代码指定自己无效的行为。
- 圣光爆裂支援项允许零治疗发动：先摸1张，再有治疗则移除1点，随后增加信仰、治疗队友。
- 式神咒束允许以两颗宝石替代一宝石一水晶；采用用户最新澄清：①先给攻击附加强制命中／无法应战效果，再在①末、原目标响应之前询问代接。强制命中或无法应战时不询问、不支付咒束费用。
- 新版吟游诗人的永恒囚徒形态在时点6减少1点实际法术伤害，适用于灵魂链接转入的伤害。它不再绑定时点3。
- 暗月斩一次移除1至2张暗月，只算一次移除操作，扣1士气；按旧代码的整组弃置事件处理。
- 圣弓自动填充是有费用时强制执行的被动；回合进行过特殊行动则不执行。圣煌辉光炮的手牌调整最多到角色手限，直接获得／暗弃，不触发普通摸牌的时点；第五杯立即停止后续士气调整。
- 时间轴继续采用用户提供的 v26.5.14；用户针对新版吟游的最新裁定优先于旧代码和表格。顺位始终为逆时针（当前座位编号递增）。

## 共用实现

- `playableCards`只扩展出牌／响应的可用实体池。精灵祝福仍在 `covered/blessing`，不计入手牌数量、爆牌、普通手牌弃置费用；实际使用才移到场上或状态区。网页底部以“祝福”标记区分，CLI显示相同可出牌编号。确认前不移动实体。
- `ATTACK_RESPONSE_BEFORE`为①末的独立响应前窗口，全部`ATTACK_DECLARED`效果完成后才进入；式神咒束在此更新实际响应者。放弃代接后才询问原目标，不能等原目标表态再回来发动咒束。强制命中／无法应战是本次攻击附加属性，不是另一个技能时点；②仍正常执行命中判断。普通响应的程序请求仍由共用攻击流程驱动，不因此改变先询问阴阳师的规则顺序。
- 同命格应战由英雄的 `canRespond`扩展合法性，但不能绕过暗灭、无法应战或强制命中限制。需要转换才能应战的牌必须执行阴阳转换；原本可普通应战的同命格牌允许选择是否转换。
- `damageAtPointSixSteps`接收已经确定的实际伤害。灵魂链接按当前回合座位顺序结算原目标和另一端，另一端伤害来源为灵魂术士，类型为法伤；不重新执行时点3至5或治疗，不再次链接转移。转移伤害不会继承原伤害的免士气标记。
- `MORALE_AFTER`包括直接士气变化和伤害爆牌，避免灵魂吞噬漏掉合成、暗月移除等来源。伤害爆牌还保留弃牌实体列表供新月庇护移入盖牌区；胜利后不再发动后续被动。
- 状态牌授予的手限修正由 `Player.getSkills()`统一计算。同生共死为唯一场外专属实体，不能按基础效果移除；流血退出在手牌移动后的规则检查点执行，手限变化立即暗弃多余牌，不额外降低士气。
- `TurnFlow.extraTurns`保存额外回合队列；月神可以放弃本次额外攻击，保留后续额外回合。该队列和新英雄状态均进入公开观测。

| 阴阳师 | 提高不同命格攻击留分；同命格转换、鬼火及式神形态计入资源。生命结界比较队友资源与自伤；代接攻击比较原目标承伤及两颗战绩星石成本。 |

| 月之女神 | 庇护比较实际士气损失；暗月移除按真实士气费用扣分，避免仅为小增伤自耗士气；新月／石化和苍白之月的法伤、后续攻击与额外回合有资源分。 |
| 圣弓 | 提高圣命格和同系攻击配对价值；普通非圣攻击计算−1伤害，圣屑飓暴估计响应概率。治疗、信仰、圣煌形态和辉光炮独立计值；支援队友、自动填充和辉光炮士气调整分别决策。 |

这是首版确定性评分，不是新训练网络，也不代表真人强度验收。对于长连锁、形态变化后续机会和队友策略仍采用近似估值，按既定流程等待试玩反馈。没有启动训练或更换模型文件。

## 观测与验证

本人祝福／暗月牌面可见，其他座位仅有盖牌数量；专属状态引用可见实体。出牌／响应候选可指向盖牌实体，弃牌候选仍只能指向手牌。新增字段保持显式声明，未向网络输入他人手牌或牌库顺序。新英雄和新状态需纳入后续词表及训练，旧检查点不会自动具备这些能力。

本批验证：

- 112项核心规则测试、6项实体接口测试通过。灵魂链接链式测试确认转移2点法伤后囚徒实际摸1张、不进入时点3、已有2治疗不被消耗。
- 14局六人完整对局全部结束，2335次决策执行实体编码；包含本批阵容及前五批混合阵容。另8局探索对局完成。这些是兼容检查，不是胜率评测。
- 桌面1440×900与触屏390×844共12项开局、14项祝福／状态交互、12项祝福响应、12项式神咒束选牌／取消／代接检查通过，无控制台／素材错误。浏览器隔离交互通过替换开发场景准备可重复局面，实际调用共用引擎和正式交互；不称为自然开局覆盖所有技能。
