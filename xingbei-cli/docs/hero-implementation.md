实现狂化、血影狂刀、血腥咆哮、撕裂，英雄可选响应与治疗选择共用Session等待。攻击上下文记录六判定时点：attackDeclared(1)、attackDecision/hitCheck/hit(2)、damageBefore(3)、healingBefore(4)、damageActualBefore(5)、damageActual(6)。强制命中仍执行时点2，不消耗圣盾、不请求应战/圣光，后续治疗正常。狂化主动和应战均生效；命中时手牌数量在时点2保存，撕裂在时点3决策并消耗个人宝石。

150张牌逐实体还原uniqueSkills，属性和命格相同可能标签不同；保留3张圣光的治疗术。标签使用英文、中文显示，未实现英雄的标签不自动提供能力。来源：card/xingBei.js完整150行牌表；character/shiZhouNian.js狂战士258—333行及技能文字；noname/library/element/gameEvent.js强制命中；layout/default/layout.css的.card > .range。未改旧项目。

## Goal 2：风之剑圣（v0.4.1）

实现风怒追击、圣剑、烈风技、疾风技、剑影。TurnFlow保存额外攻击行动及风系限制，优先消费最后获得的限制行动；玩家可以直接结束回合放弃剩余行动。启动只执行一次，主动攻击逐次计数，应战不计入第三次主动攻击。圣剑在第三次攻击的时点2强制命中；行动结束可以摸0至3张并暗弃同样数量，先完成换牌再判断剩余爆牌。烈风技忽略圣盾并禁止应战，仍允许圣光。水晶费用可以选用宝石代替。

网页、终端与AI共用额外行动队列，网页限制不能使用的手牌并提供结束回合；终端使用end。默认测试0号风之剑圣、1号狂战士，其余角色技能尚未实现。技能来源character/shiZhouNian.js及原版额外行动队列，未修改旧项目。

## Goal 3：神箭手（v0.4.2）

实现闪电箭、贯穿射击、闪光陷阱、精准射击、狙击。行动技能由Game验证费用与目标后才进入法术行动；网页、终端、AI共用合法技能描述与结算。费用牌和目标选择都可以取消，目标提交前不扣费。贯穿射击在主动攻击未命中后询问是否明弃法术牌，再造成2点法术伤害，不建立新的法术行动。精准射击支持主动与应战；闪电箭仍允许圣光。

狙击直接补手牌至5，保留directDraw来源，绕过伤害与治疗时点；爆牌仍暗弃并降低士气，再获得可放弃的额外攻击。正式手牌上限不变，隔离场景神箭手上限4测试自狙击爆牌。来源character/shiZhouNian.js1329—1450行及技能文字。

## Goal 4：封印师（v0.4.3）

实现法术激荡、五种封印、五系束缚、封印破碎。封印为带对应独有技的基础攻击牌挂载，禁止同名重复，每张牌独立保存来源。共用cardExposed事件保存离手前有效属性：使用、手牌展示、明弃触发；暗弃、covered盖牌标记及状态牌离场不触发。规则事件队列在规则检查点处理，与动画队列无关。

有封印师时登记唯一fivefoldBinding专属实体，初始outside；费用支付后挂到对手，触发后返回outside，可复用；无封印师不生成。优先级中毒3、束缚2、虚弱1。束缚摸牌数2+min(2,场上封印实例数)，若有虚弱再加3，一次选择、同时移除虚弱；可以选择跳过。封印破碎只收入基础效果牌，清除attachment并保留原实体，不收专属牌。来源character/shiZhouNian.js616—1118行及技能文字。
