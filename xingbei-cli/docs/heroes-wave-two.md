# 第二批六英雄实施记录

本批暂停AI迭代，新增圣女、圣枪骑士、瘟疫法师、元素师、女武神、魔法少女。它们覆盖治疗、命中技能、群体法术、资源指示物、横置形态和魔弹转化，能复用现有规则体系；暂未选择需要盖牌、灵魂链接等额外体系的角色。依据为原项目十周年包`character/shiZhouNian.js`的技能文本与实现，以及现有基础牌独有技标签。

## 实现范围

| 英雄 | 技能及重要约束 |
| --- | --- |
| 圣女 | 冰霜祷言、治疗术、治愈之光、怜悯、圣疗。祷言仅使用水牌/圣光触发，明弃不触发。怜悯横置后手限恒定7；有宝石时可再次启动，与原版合法性一致。圣疗每回合一次，分配3治疗给1至3人并选择额外攻击/法术。 |
| 圣枪骑士 | 神圣信仰、辉耀、惩戒、圣击、天枪、地枪、圣光祈雨。天枪禁止应战但仍允许圣光和圣盾；地枪在时点2先于圣击，天枪/地枪与圣击互斥。圣光祈雨可突破普通治疗上限至5，并在本回合禁用天枪。 |
| 瘟疫法师 | 不朽、圣渎、瘟疫、死亡之触、剧毒新星。治疗上限+3但不能抵挡攻击伤害。死亡之触同系牌与治疗数量均至少2，不触发不朽；瘟疫造成士气下降后在回合结束补一次治疗。群伤包含其他队友，胜利后立即终止后续效果。 |
| 元素师 | 元素吸收、元素点燃、陨石、冰冻、火球、风刃、雷击、月光。元素上限3，点燃不触发吸收；五种独有技可额外明弃同系牌增伤，分别实现追加行动、治疗和星石。月光按支付后剩余能量计算。 |
| 女武神 | 神圣追击、秩序之印、和平行者、军神威光、英灵召唤。秩序之印摸牌是非伤害；英灵召唤命中时发动，自身回合发动后横置，主动攻击时重置。回合开始选择自疗重置或消耗1至2战绩星石给目标治疗。 |
| 魔法少女 | 魔爆冲击、魔弹掌握、魔弹融合、毁灭风暴。主动魔弹可逆向；响应沿原方向；火/地牌转化不改变实体身份。魔爆目标明弃法术，否则受伤且施法者暗弃一张牌。 |

默认阵容、六人红蓝蓝红红蓝坐次不变；新增英雄通过开局选择替换玩家座位。全部12位可选英雄共用网页和终端入口。旧英雄开发场景改用未实现的吟游诗人占位，避免原本占位的魔法少女突然获得技能。

## 验证

- 全套Node规则测试270项通过，其中新增12项链式测试覆盖六英雄、费用与目标、额外行动、时点、终局中断和牌实例守恒。
- `tools/verify-heroes-wave-two.mjs`在1440×900和390×844触屏视口63项检查通过，浏览器/HTTP错误0；涵盖12人选角入口、六人坐次、主要技能交互、取消与逆向魔弹。截图与JSON位于`artifacts/heroes/wave-two/`（本地证据）。
- 另12个固定种子的六新英雄完整AI对局正常结束，每次行动后检查牌位置守恒；这是兼容性检查，不是英雄策略强度测试。
- 新增5张原版头像，魔法少女头像已存在；更新资源映射与SHA-256清单。原项目不修改。

复现：

```sh
npm test
HOST=127.0.0.1 PORT=4186 TEST_MODE=1 node server.js
# 另一个终端，环境已有Playwright时：
BASE_URL=http://127.0.0.1:4186 node tools/verify-heroes-wave-two.mjs
```

Playwright可通过`PLAYWRIGHT_MODULE`指定安装路径。开发场景分别为`hero-saint`、`hero-holyLancer`、`hero-plagueMage`、`hero-elementalist`、`hero-valkyrie`、`hero-magicalGirl`。

## 边界

本批是规则与可操作界面实现，没有训练新模型或为新英雄调优AI。现有策略可完成对局，但不会保证善用新增技能；旧模型的强度结论只适用于原有阵容。测试场景的牌与资源是确定性准备，不是自然开局证据。新增状态标记及横置头像采用原素材，尚未完成与旧版每个动态状态逐像素对照，不能宣称整体视觉还原。4173/4174现有服务与训练任务未改动，本批保存在独立工作树和分支，未部署。
