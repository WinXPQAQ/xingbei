# 终末祷铸五英雄：0.14.0 / AI 1.14.0-preview.1

本批实现铸律者、红衣主教、记录者、传教士、异教徒，共53位可选。噬神者按用户要求暂不实现。体验服仍为六人红蓝蓝红红蓝，默认阵容为本批五位加神秘学者。

## 规则与基础AI

各英雄的规则、评分与观测声明在 `src/heroes/<英文名>/index.js`、`ai.js`、`observation.js`。铸律者／红衣主教的共享资源、治疗费用和换角色操作复用 `lawgiver/shared.js`；技能主体各自在自己的目录。依据为原项目 `character/zhongMoDaoZhu.js`、用户提供的结算时间轴及本次放逐修订。

## 用户确认的放逐修订

**无视手牌上限摸6或7张牌，然后选择6张基础牌洗混放入预言堆。**

摸牌走普通流程，不筛选、不跳过牌堆中的专属牌。限制的是随后选出的6张材料，使用 `category === "basic"` 判断；史书和未来噬神者的刃均不能成为这些材料。摸牌期间临时忽略手限，材料放置完成后恢复手限并检查爆牌。使用次数、能量费用和额外行动保留。

预言堆对所有AI隐藏具体牌面和洗混后的顺序，持有者也不例外。正常页面显示牌背；测试／观战仍可用既有调试展示。正面名称公开，预选灾殃面只进入持有者的结构化观测，翻面后公开。

## 共用接口和顺序

- `Game.replaceHero`替换英雄实例并重新注册触发器，共享资源和王权宝珠实体ID保留，旧订阅失效；前端随真实英雄更新头像和技能。
- `HEALING_CHANGED`记录实际治疗变化；神律封锁按每次实际增加扣一次士气，下限1。`changeMoraleSteps`提供非伤害士气下降的响应窗口；月神、兽灵武士、圣弓、女仆长对应士气操作也接入。伤害爆牌仍走原有伤害原因，不误触发罪断豁免／神宣祷言。
- 路标不改变玩家编号、阵营和目标顺位。`TurnFlow`跳过已开始跟随的传教士原回合位置，在路标持有者回合结束后安排传教士，再回到保存的正常后继位置。左侧传递沿座次递减寻找合法角色，王权宝珠右侧传递沿座次递增；传教士不能成为路标目标。
- 史书是地系幻命格攻击专属牌，使用、弃置或交出时回到场外，攻击上下文继续保留该次牌和属性，避免伪造第二张史书。史书身份及位置是公开信息；普通手牌和预言牌不因此公开。
- 公开遗迹与临时展示牌继续使用实体区域。知行合一执行对应内层行动后恢复外层，剩余展示牌进入弃牌区并获得史料；未把揭示牌加入普通手牌计算。
- 伤害摸牌通过`DRAW_BEFORE`提供第1张替代实体；其余张数仍从普通牌堆摸。最后预言对应的伤害结算完成后才翻面，嵌套伤害不能提前触发。灾殃各次费用、摸牌、目标弃牌、法伤依次结算，胜利立即终止剩余效果。
