# 第五批英雄：0.10.0 / AI 1.10.0-preview.1

实现灵符师、剑帝、魔弓、苍炎魔女、血色剑灵、兽灵武士，共30位可选英雄。仅使用十周年角色包；规则、评分与观测声明均在各自的`src/heroes/<英文名>/`目录。继续采用六人红蓝蓝红红蓝坐次。测试服务4174默认本批阵容，玩家选角替换0号。

## 明确裁定

- 魔弓雷光散射全部为法术伤害：先一次性支付X张雷充能，再按施法者起算的座位顺位逐人结算；普通敌方1点，指定敌方X点。胜利立即结束后续结算。
- 兽灵逆反居合斩仍算命中，保留命中战绩与技能，只以弃牌替代该次攻击伤害。不进入伤害3至6时点，也不改判未命中。
- 命中战绩统一提前到命中技能之前，包括旧英雄；战绩已满则不补发，后续技能腾空战绩也不追补。
- 用户提供时间轴的核对记录见[timing-reference-v26.5.14.md](timing-reference-v26.5.14.md)。当前页面1号在右、5号在左，编号递增为逆时针，和表格及用户“顺位”的裁定一致。曾提出的方向冲突系左右座位识别错误，已更正。

## 共用支持与规则边界

`Player.covered`和`location: {zone: "covered", playerId, pile}`承载盖牌，统一走牌登记／移动接口。妖力上限2、剑魂上限3、充能上限8，牌ID始终不变。盖牌不是基础效果；展示移除盖牌也不触发封印。私有日志遵循正常／测试模式开关。

正常页面只有持有者能查看自己的盖牌，其他座位显示牌背和数量；测试／观战可见牌面。状态区盖牌标记可展开查看，显示命格，窄屏向内展开。血蔷薇庭院为开局场外的唯一专属实体，场上时禁止所有角色使用治疗抵伤，不影响获得治疗；拥有者回合结束返回场外。

`FORM_ENTERED`在技能效果完整结束后发出，包含嵌套摸牌及伤害；兽魂警戒由规则订阅，不从日志或动画判断。红莲首次进入热血沸腾改到实际士气下降之后，避免过早触发兽魂警戒。苍炎魔女重置在中毒／束缚／虚弱之后，降低手限即时处理爆牌。

魔弓多重射击使用无实体的暗系攻击描述，独立计入额外攻击行动；目标排除上次主动攻击目标，伤害1，可继续消耗风充能。该额外行动不能换成普通手牌攻击。兽灵一击无念只强化其对应的额外攻击，强制命中仍经过时点2。

## 基础AI

| 英雄 | 本批评分重点 |
| --- | --- |
| 灵符师 | 保留雷／风作为灵符费用，火牌兼顾妖力；评估双目标伤害、弃牌和念咒储备；灵力崩解比较增伤收益。 |
| 剑帝 | 提高攻击留牌，计入未命中后的剑魂和剑气价值；剑气按1至3点比较收益；不屈意志需有后续攻击并考虑摸牌风险。 |
| 魔弓 | 火／风／雷保留与盖放用途，优先准备不足的充能；魔贯根据目标法伤压力选择，雷散比较目标与费用数量，多重射击使用风充能。 |
| 苍炎魔女 | 提高火和前两张法术的价值；双向伤害计入自伤，重生较充足时进入烈焰；魔能反转比较弃牌和能量成本。 |
| 血色剑灵 | 计入鲜血、命中及追加攻击价值；散华比较双方治疗压力，血气屏障比较减伤与反击，赤闪避免无效自伤。 |
| 兽灵武士 | 偏重攻击与接近一击无念时的技命格；兽魂和残心有资源分；逆反居合斩比较弃牌／士气结果与普通伤害；不提无用水晶。 |

这是首版确定性评分，并非新训练网络或强度验收。旧英雄沿用当前评分模块，冻结v1.5源码不变。多次追加攻击的长程机会成本和多人反击仍是近似估计，等待用户试玩反馈。

## 观测与网络接口

所有新增英雄状态均有声明。规则AI和结构化实体编码都只读取本人的盖牌牌面、其他玩家盖牌数量；盖牌选择通过本地实体指针表达。未读取其他人的盖牌或未来牌库。

没有修改网络结构或启动训练。新英雄／状态／盖牌特征需纳入后续训练词表；旧检查点不因接口可编码就具备新英雄能力。4174继续使用确定性规则AI。
