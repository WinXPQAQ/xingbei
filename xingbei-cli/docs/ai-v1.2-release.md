# AI v1.2 验收与独立审查（2026-10-19）

产品验收后，稳定 `v1.2` 映射已冻结的 `fusion-1`，CLI/Web/引擎共用 `src/ai.js` 默认为v1.2。`v1.0`冻结文件及`v1.1 = read-1`语义保留；应用版本仍0.6.3。没有调权重或新增调参比赛。

## 可读策略变化

- 共同：用预期命中收益与士气损失替换旧攻击加分，计入留牌成本。吃刀历史依据当时公开预计爆牌代价调节证据强弱；低代价吃刀证据弱，高代价仍只是软证据。只用固定公开牌表，不读取实际牌库。
- 狂战：计狂化伤害、血影对2/3手的加伤、咆哮的2治疗强制命中条件、可支付撕裂及能量成本；在命中概率和有效损失之间取舍，不只偏好高手牌目标。撕裂技能选择仍继承旧策略。
- 风剑：最多搜索第三次主动攻击，使用自有攻击牌、真实风系限制、风怒/剑影次数和能量预算，估计前刀命中后的手牌/治疗变化。第三刀强制命中，风刀本身不等于必中。每次行动重新决策，不保证执行同一预测序列。
- 神箭：计雷箭不能应战、精准强制命中的减伤，以及未命中时贯穿弃法术牌的成本；闪光陷阱、狙击等非攻击技能仍沿用基线评分，未加入统一序列搜索。
- 封印、天使、神官保留既有主要技能/资源策略，攻击采用新的统一收益评价。防御、弃牌及多数技能选择保持基线逻辑，均通过新观测适配器调用。

已知效率局限：在火刀、风系疾风、土刀且有1水晶的构造状态，融合版会支付剑影、打三刀后放弃冗余行动；旧v1.1可保留该水晶。此行为已包含在冻结候选统计中，不是非法行动。本次保留并新增执行回归，不为追求局部收益改策略。原精确三刀/不花水晶断言保留为v1.1版本测试。

## 冻结统计与六阵容

独立审查从原始逐局数据重算，与报告一致。每个总体4800局、每格800局；整种子簇4000次bootstrap，括号为双侧95%区间。

| 阵容 | v1.2/fusion 对 v1.0 | v1.2/fusion 对 read-1 |
| --- | --- | --- |
| 强攻：狂战/风剑/神箭 | 60.75%（57.75–63.63%） | 56.75%（53.38–60.13%） |
| 法术：神箭/封印/神官 | 66.75%（63.50–69.88%） | 56.88%（53.25–60.38%） |
| 支援：封印/天使/神官 | 87.13%（84.88–89.38%） | 79.38%（76.38–82.25%） |
| 混合：狂战/天使/神官 | 86.13%（83.63–88.38%） | 70.50%（67.00–73.75%） |
| 节奏：风剑/封印/天使 | 78.13%（75.13–81.00%） | 68.25%（65.13–71.25%） |
| 压迫：风剑/神箭/神官 | 68.00%（64.88–71.13%） | 58.63%（55.25–62.00%） |

六阵容均未观察到退步，区间下界均>50%。另对read-prior为66.73%（65.54–67.96%）。通过预登记的三对手总下界>50%、对v1.0各阵容下界>45%的合取门槛。无历史对照虽然总体58.54%，强攻46.88%（43.63–50.13%）未通过非劣门槛，未作为产品默认。

仅六个镜像阵容、先手座位0/1、固定策略对手；非全部英雄组合/座位/真人水平。三种对手共享种子，不能合并成独立样本。历史模块的独立收益尚未经同架构消融证明；整体提升不能全归因于读刀。

## 独立隐私审查与实际边界

两名独立代理分别审查隐私/实际路由与融合/统计；未改策略。最终结论需区分：

| 路径 | 证据与边界 |
| --- | --- |
| 行动排序、攻击选择 | `isolatePolicy.rankAiActions`先生成自身actorId的独立观测，再调用策略；无原始Game引用。 |
| 防御与应战 | `chooseAiResponse`以response.target.id重新生成观测，其他玩家只有公开信息/牌数；有效响应牌来自自己的手牌。 |
| 技能/规则选择 | `chooseAiRuleDecision`以request.playerId或player.id生成观测和筛选请求。 |
| 弃牌、留牌、赠牌评分 | 相应wrapper用该玩家自身观测与牌副本；overflow的选牌在副本中计算，实际弃牌由外层引擎执行。 |
| 嵌套响应 | CLI/Web调用共用入口；引擎自动决策与同步runner按每个请求玩家重新路由到以上wrapper。路径经过源码核对及整局测试，并非全分支形式证明。 |
| 观测采集、合法动作/属性查询、公共历史生成、结算 | 仍持有完整Game，是受信任规则代码；已审查当前六英雄生产者，但没有隔离到只能访问公开字段的独立规则进程。请求choices/defaultValue等复制字段也依赖可信生产者只提供合法可见内容。 |
| 冻结v1.0、辅助Proxy | v1.0仍接收Game，仅审查/测试未发现隐藏读取；Proxy反射可绕过，不能称安全边界。 |

融合搜索仅使用自身现有攻击牌、公开数量/治疗/资源及期望变化；未读取真实未来抽牌或他人牌面。它未模拟应战链、封印连锁和不同目标的全序列，不能把期望模型当真实未来。

54组反事实为六英雄×三种人工公共状态×三次隐藏置换，固定观察者0；比较观测、完整排序/分数、行动、响应、弃牌、六类规则请求和两种信念。其他五人牌面及牌库顺序确实变化。响应与规则请求是合成样本，没有覆盖全部座位、所有选择类型、真实嵌套链的每个分支或公共历史生成过程。

## 审查发现、修复及旧结果适用性

发现盖牌明弃日志隐藏牌面，却因`covered`未传入`moveCard`而把属性写入公共历史。已传播标志并抑制此路径的属性记录；普通明弃仍记录。未改变牌移动、可见性字段、伤害或技能触发。独立复核单张/批量盖牌弃置、实例守恒通过；增加回归测试。

现有六英雄生产技能没有`covered:true`调用，旧19200局不涉及该路径。因此旧结果仍适用于原评测范围，不能扩展到包含该泄漏的旧盖牌场景。修复后对三种对手各重放72局，共216局，初始牌局、赢家、回合和全部指标与冻结结果完全一致；不是新胜率样本，也未全量重跑19200局。融合及观测算法文件哈希未变；变化仅稳定别名、默认入口和上述历史生成修复。
