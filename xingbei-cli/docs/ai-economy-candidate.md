# 手牌经济候选（v1.3 工作名）

生产默认保持 v1.2。当前候选注册名 `experimental/economy-2`（原 economy-1 已因性能拒绝），未将 v1.3 名称用于稳定发行。旧 v1.0、v1.1/fusion 源码不变。

## 设计与边界

`src/ai/v1.3/model.js` 是仅接受白名单观测的纯近似状态评价；`planner.js` 枚举支付后的结算分支；`index.js` 比较合法行动与放弃的预期状态差。分数是启发式团队效用，不是伤害值或校准胜率。

评价分别记录士气/终局、星杯、有效星石、下次合成期权、自身手牌、其他玩家手牌、治疗、可兑现能量、公开效果、自己及其他角色下次行动前的风险。出牌、伤害、命中、减牌、提炼、赠牌均没有独立固定正奖励。命中只按真实容量增加星石；伤害补给对手可以是负收益。手牌包含属性覆盖、暗/圣光防御选项、攻法互补和重复拥堵；它们仍是可解释的手工估值，尚未校准为胜率。

末端估值使用公开座次、手牌数、角色、能量、治疗和状态，估计下一次有效行动前的压力；队友神官可降低部分压力。未知防御按公共先验估计，不读取其他手牌。有限计划包含神箭攻击/贯穿、神官支付/强制赠牌、封印师法术后攻击、风剑至第三刀，以及魔弹前两次目标判定。每个分支支付资源一次，比较末端状态差；普通、额外和响应机会不重复收取固定行动费用，普通行动的机会成本通过相互比较体现。

公开封印支付计入伤害、治疗、补牌、庇护和解封；神圣领域暗弃不触发封印。支付后摸到未知牌不被当作可指定攻击牌，但会参加强制赠牌数量结算。神官赠牌只用自己的牌面与受赠者公开信息。真实请求增加水神力/破封技能标签和公开伤害类型；这些是决策元数据，不改变规则结算或旧策略评分。

`traceDecision(game, observerId, request?)` 返回观测、白名单请求、结果及可用评分分解；不会推进引擎。`replayTrace(JSON.parse(JSON.stringify(trace)))` 只用记录重放。不能把评测器的私有初始数据或测试/观战日志作为策略输入。候选测试覆盖六座位、候选与两消融、行动及嵌套请求的暗牌/牌序反事实和跟踪无副作用。

## 已知近似

- 隐藏牌采用固定印刷牌先验和公开历史；不是完整贝叶斯牌组计数。
- 对手反击目标取公开估值较不利的队友，再用概率估计其应对；没有搜索完整反击链。
- 魔弹尾部没有搜索到全链终止，移除效果后的角色联动、神圣契约等少数可选/强制技能仍部分沿用旧合法决策辅助。不能称所有英雄分支都已统一精确求解。
- 未知摸牌用数量与平均牌值表示，不能搜索新摸到的具体牌；未知牌溢出保留、响应概率和双方未来资源兑现均有偏差。
- 风剑有限规划不穷举全部排队额外行动组合；实际每次机会重新用合法观测决策。
- 次回合风险是末端启发式，不是把其他五人完整行动展开的搜索。
- 六种子簇、三阵容验收只是开发质量门；即使通过也不代表真人强度。

## 验证与评测

协议在 `artifacts/ai/economy/protocol.json`。开发种子61001；验收72001–72006，先手0–5、成对换色，同时交换非镜像双方角色阵容。每对216局，300回合上限，截断计半分且单列。候选对v1.2/v1.0和独立评分风格flow/reserve；另测v1.2对风格对手、两消融对v1.2，共1728局。风格对手使用独立行动/响应评分，但共享合法枚举和部分强制规则辅助，不应称完全独立强AI。

初始训练12局4胜8负，发现反击被估为必然命中、缺少合成门槛期权；修正后同一训练样本8胜4负。两次报告保留在train目录，均为未冻结开发代码，不能作为验收证据。验收前冻结源代码，之后不根据验收分数调整权重。

指标除胜负外包含高牌回合、模型定义的无可兑现用途能量回合、主动支付暗/圣光次数、赠牌瞬间手牌势能差、受赠者到下次回合时是否仍高牌。主动关键牌次数统计整个行动结算链中的暗/圣光离手，可能包含响应、赠牌或溢出，不能视为纯主动费用；赠牌指标是观察性统计，不代表因果净收益或最优行动遗憾。

```bash
npm --prefix xingbei-cli test
node --test xingbei-cli/test/ai-economy.test.js
node xingbei-cli/tools/evaluate-economy.mjs experimental/economy-1 v1.2 acceptance /tmp/economy-v12.json
```

独立审查发现并修复精准DTO克隆、trace执行溢出、反击目标/顺序、神圣领域公开支付、未知摸牌强制赠牌、庇护虚假终局、魔弹圣盾、重复风怒/剑影和破封元数据等问题。最终审查无已确认阻断，支持评测，不替代强度门。完整规则测试109项通过，候选11项正反/隐私测试包含在内。结果和候选SHA将在验收后另行记录。


## 有界性能修正版 economy-2

首候选 a9afb9614dde5af5a25bbb2fcdf11c5fc6ed44a3 在满风牌、两能量、完整公开历史压力状态超过30秒，因此不具备发布资格。其四个策略文件逐字节保存在 src/ai/v1.3-a9，economy-1 及原消融别名保持原行为。

待验收版本改为 experimental/economy-2：同次决策只构造一次只读历史和公共信念，各分支仍独立复制可变玩家/团队/回合。每个根行动最多128次 planAttack 展开，深层续刀只对即时评分前两项继续搜索（允许负即时收益）。这会改变策略行为，需要独立新验收；128不是整次排序总展开数，也不是通用墙钟时间保证。束宽截断可能遗漏先亏后赚的序列。

新协议 bounded-protocol.json 使用82001–82006、全部六个先手、换色、两个镜像阵容及两个非镜像英雄分配，每对288局、八对共2304局。非镜像两种分配合并作为平衡阵容门槛，另外各自报告。权重不变；不继承旧候选胜率。全量112测试通过；冻结a9的10个JSON场景重放一致。正式默认仍为v1.2，待父线程验收后发布。

最终验收结果、候选SHA、全部门槛和剩余限制见 [有界候选验收](ai-economy-results.md)。上述旧候选训练与初次验收描述属于历史，不是当前验收统计。
