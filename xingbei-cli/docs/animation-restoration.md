# 六人局动画与交互细节（v0.3.0）

本批只覆盖当前六人红蓝蓝红红蓝、玩家0号红一的已支持规则。以原版 music + nova 为基准打磨衔接，不增加音效、历史界面或真实英雄技能。用户已授权将本批改动提交并直接push到main。

## 原版依据与实现范围

原版动画位于 `noname/library/element/player.js` 的 `$draw`、`$throwordered2`、`$damage`、`$damagepop`，以及 `noname/game/index.js` 的 `linexy`；默认 transition、浮字与线条样式见 `layout/default/layout.css`。原目录没有修改，适配继续遵守 SOURCES.md 与 GPL-3.0 说明。

| 效果 | 本批行为与基准 |
| --- | --- |
| 摸牌 | 中央起点，800ms飞入；本人到对应手牌位置，对手到玩家区域，未公开牌只展示原版牌背。开局依座次展示六次真实发牌结果 |
| 出牌、弃牌 | 500ms进入中央处理区；连续响应保留已公开牌，最多4张一排，后续清理再继续；选中牌从当时屏幕位置起飞，不先落回手牌 |
| 状态牌挂载 | 中央展示后400ms飞抵目标，抵达后才出现状态标记；移除按真实牌从状态区移到处理区 |
| 连线 | 原版3px渐变线，1000ms展开与淡出；攻击与牌飞入并行，魔弹每次实际传递单独标明来源和目标 |
| 命中与抵消 | 来源方向受击偏移并恢复；72px原版字体显示实际伤害，中毒逐张触发；圣光/圣盾显示未命中，不播放命中伤害 |
| 回合与资源 | 回合头像轻微放大恢复；星石获取、提炼有原素材移动，士气、能量、治疗、星杯与获胜有对应浮字 |
| 操作细节 | 选牌/取消/整理平滑重排，材料选中反馈、弹窗进入/退出；不改圣光确认、应战/魔弹点目标提交的原则 |

为提高可读性新增状态名、未命中、资源变化文字；状态挂载衔接、浮字700ms和清理250ms属于本批打磨，不宣称原版逐帧一致。中央牌展示是呈现副本，不把实际已弃置的牌重新移动到规则field区域。

## 结算和呈现边界

`Game.enablePresentation(callback)`启用可选呈现。同步操作记录结构化事实与独立状态快照，生成器在决策和结算边界通过 `present()` 发出 `presentation` 请求；异步驱动等待回调，同步驱动消费但不等待。各异步入口也接受 `onPresentation` 覆盖默认回调。终端默认不启用呈现。

事件包括move、draw、discard、relay、effect、damage、miss、stones、morale、cup、energy、healing、turn、shuffle、winner和clear，使用牌ID、来源/目标玩家ID及数量，不从中文日志推断规则。批次快照只用于展示，牌登记和实际区域仍归Game维护。动画不消耗随机数、不重复出牌，也不推进current。

网页将快照适配成渲染视图，主要动画完成后才继续请求响应。玩家节点按ID、手牌按牌ID保留，牌面内容只在变化时更新；坐标从屏幕转换为当前arena逻辑坐标。素材和静态对局布局沿用之前基准。

动画绑定Session，重开/重置取消所有旧等待、节点和监听器；动画中禁用重复提交和整理。后台切换完成动画，窗口变化结束当前轨迹并更新布局。遵循 prefers-reduced-motion；关闭动态时保留实际状态与操作提示，取消飞行和等待。

## 开发入口和证据

正式游戏：`http://服务器IP:4173/`，测试服务显示v0.3.0，继续监听0.0.0.0。普通刷新即可获取新JS/CSS。

开发页：`/web/dev.html?scene=opening`。新增连续中毒、圣盾抵消、无法行动重摸、对手摸牌和第五杯结束场景，均通过实际牌移动与规则准备。工具栏可暂停/播放效果、单步一个结构化效果、结束当前动画和关闭动画。`window.xingbeiDev.animations()`导出运行状态和事件时间线；不暴露在正式页面。

采集原版：`tools/capture-original-animation.mjs`。证据 `animation-original-3/`包含在隔离六人配置中实际点击出牌到命中/摸牌的调用顺序与录像；随后用原版呈现方法隔离采集摸牌、出牌、线条、受击和回合反馈。不能把这些单项隔离调用描述为全部自然业务通过。原版/checkFile和缺失素材404继续记录在issues.json，未修改原目录。

当前验证使用现有整体、应战、魔弹工具，以及 `tools/verify-animations.mjs`。整体和专项等待真实动画稳定，不通过关闭动画代替动态验收；日常仍不进行逐像素重置比较。最终检查数量、证据路径和范围记录在 frontend-restoration-2026-10-10.md。

自然应战/魔弹全链的原版录像、原生移动设备分支和所有英雄效果仍未完成逐项对照。新动画已接入目前规则，不等同于所有前端完全还原。


最终结果：36项Node测试通过；整体108、应战49、魔弹51项两视口回归通过；包含正式入口开局的四视口动画专项89项通过，合计297项浏览器检查。最终证据为animation-release-general/、animation-release-attack/、animation-release-magic/、animation-release-detail/，控制台与素材错误0。动画开始前预加载解码11种基础牌面、牌背及星石，使用已有24小时本地缓存；原版资源文件不变。录像索引可通过 `/review/restoration/2026-10-10/animation-review.html`查看。


v0.3.1后续修正：无合法响应牌也进入共用选牌界面，点击“取消”后继续命中检查；引擎damageType明确区分attack/spell（魔弹、中毒为spell）；爆牌保存hidden弃牌可见性，动画牌背、日志仅数量；攻击/魔弹及响应牌先进入field，完整结算后本次仍在场上的牌一起明弃，挂载牌保留status。爆牌确认后立即刷新呈现检查点。接口见game-architecture.md，验证结果见frontend-restoration-2026-10-10.md后续记录。本次不提交commit或PR。


v0.3.2统一响应提示：按用户最新要求移除无合法牌时的提示和按钮文字分支。所有响应始终显示相同标题与“不响应”；合法手牌逐张按相同规则启用，空合法集合自然全部禁用。“取消”只撤回当前选牌；“不响应”统一返回null，交给引擎继续命中检查。覆盖之前v0.3.1无牌专用“取消”文字。
