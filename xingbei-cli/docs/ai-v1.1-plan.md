# AI v1.1 实施方案

基准：31007a8；v1.0 为该提交 AI 五个文件的独立副本（仅入口相对路径调整）。禁止改变规则、使用他人隐藏牌或未来牌序。当前本地分支开发，不推送。

1. 保留可选择版本，完整隔离行动、响应、技能、治疗、弃牌；评估不使用引擎默认新 AI 作为旧 AI 的后备。
2. 增加只含公开信息的有限历史：摸/交/暗弃仅数量变化；公开出牌记录当时属性；命中记录是否强制/可应战。拒绝响应只算软证据；摸牌、弃牌、出牌、回合流逝衰减旧信息。
3. 首个候选只启用读刀模块，响应、技能和弃牌仍为v1.0。另保留关闭历史、半权重消融。根据实际规则估算应战与圣光概率、盾和必中；比较实际士气威胁、星石、对方补牌和响应消耗，保留风剑合法连击规划。
4. 防御和英雄威胁作为独立开关与实验候选，不未经验证一并发布。防御比较吃刀和响应，考虑保留圣光/暗灭、狂战伤害、封印触发、神箭贯穿、神官领域、风剑后续必中及己方临近败北。概率与权重是启发式，不宣称精确贝叶斯或最优策略。
5. 版本化镜像三英雄评估；固定红蓝蓝红红蓝，每种子对同一局面交换策略颜色并分别从红一/蓝一开始，共4局。覆盖强攻、法术、支援、混合阵容。调参种子1起，留出10001起，冻结实现后一次留出；所有试验保存。
6. 胜率（含截断按0.5分）、按种子簇bootstrap区间为主；分阵容、颜色、先手及原始逐局结果同时报告。截断单列，不视为规则平局。记录攻击/命中/实际伤害/士气损失/资源收益。另检验v1.0自对弈、隐私不变性和完整测试。
