# 全英雄连续训练（2026-11-03）

规则以7d0bd3f的72英雄为基础。本批另外修正格斗家斗神天驱的布尔决策误用于弃牌问题，并按用户明确裁定：女仆长主动用真·摹影耗尽手牌且没有后续合法行动，构成恶意无法行动，己方判负。该判负由明确的主动技能调用，不从被动弃牌或对手效果推断。

## 训练协议

- 新入口：`training/entity/run-all.py DIRECTORY --revision REVISION`。运行目录保存独立源码快照和manifest，固定规则、管线及模型版本；不跟随main热更新。
- 共享实体策略、候选评分、独立参数价值网络；entities-v3接口不变，新词表覆盖72英雄和技能/状态字段。只用终局±1团队奖励，保留熵正则；没有评分奖励或持续模仿损失。
- 先生成2400个完整教师对局，各英雄200次，座位差不超过1次。教师使用固定快照的v1.9.0-preview.1。每局完整决策均编码检查，但监督数据按每座位保留一个确定性抽样决策，限制内存；保存完整可重放残局前缀。12000步、batch32的有限预训练，整局分割验证集。
- 每轮192局、16个持久Node模拟进程，2遍PPO更新。50%自博弈、25%规则AI、25%历史模型；无历史时用当前模型补足。最多8个历史陪练版本，独立模型路由，历史模型轨迹不混入学习样本。
- 每轮保存模型、优化器、CPU/CUDA随机状态、词表、规则revision、课程进度、英雄覆盖、父模型及陪练信息。恢复时采用同一配置；中断采样重做未完成轮，不承诺异步调度下逐随机动作完全一致。

## 真实残局

仅在完整回合边界、无待结算爆牌/公开规则事件时采集。记录初始配置、种子、完整选择索引与候选哈希、边界全状态哈希。恢复通过真实引擎重放，不直接注入英雄状态。前缀不请求模型，不进入训练轨迹。

残局：双方士气≤5，或任意一方≤3，或任意一方4杯；否则中盘：任意一方士气≤8或至少2杯。首5000完成局按50%残局/25%中盘/25%全局，至15000局30%/30%/40%，随后15%/15%/70%。缺局面补完整对局，每批同一来源至多一次；每个类别保留最近10000个不同来源，局面不修改士气。教师验证集来源不参与课程训练；小时评测另用独立固定种子。包括牌序的完整状态只在引擎/本地诊断中，策略仍按座位隔离。

## 评测与运行

训练连续运行，到期在轮次边界评测：对规则AI和当前最佳模型各288局，对旧1.5原六英雄72局；每个种子换边，报告种子簇bootstrap区间和各英雄参与表现。重复用于选模的结果是开发评测，不是最终泛化验收。评测截断视作异常；训练截断不作为失败奖励。不同阵容/英雄组合的单英雄数字不等于可归因的英雄强度。

每小时本机timer生成JSON与文本分析报告；不自动唤醒聊天代理。包括状态、采集进度、英雄覆盖、课程分布、采样/打包/推理/更新耗时、开发胜率以及进程级GPU采样。GPU显存不足1800MiB则等待；不终止其他服务。所有规则/接口异常整体停止并保存完整现场，不自动重试。日志在运行目录及`corpus/rule-failures`。可运行 `node training/reproduce.mjs FAILURE.json` 重放选择序列；模型推理/教师选择本身的错误还需对应模型或教师重跑。
