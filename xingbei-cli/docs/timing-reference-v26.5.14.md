- 逆反居合斩仍算命中，只替代伤害。旧源码改判未命中的做法不采用。
- 雷光散射全部为法术伤害，开始时支付X张雷充能并指定加强目标，按顺位依次造成普通目标1点、指定目标X点伤害；胜利后终止后续结算。

- 永恒囚徒形态采用用户最新补充：时点6实际法术伤害−1，灵魂链接转移伤害也适用。灵魂链接不重新经过时点3至5或治疗抵挡；当前已实现技能中，永恒囚徒是能降低该转移伤害数值的例外。限制士气损失与减少伤害数值是不同机制。
