# AI 1.5 基准上的学习调整（本地实验）

用户于2026-10-21同意改为混合策略：保留冻结的AI 1.5作为决策基础，神经网络学习调整。此授权替代此前“独立模型、不依赖旧策略”的路线限制；终局胜负奖励、隐私、独立留出验收、本地隔离、不改线上服务等约定继续有效。旧失败实验和检查点保留，不恢复已暂停的旧训练。

## 初始行为与训练行为

`training/teacher.mjs`把1.5的实际选择映射到完整合法候选集合；`worker.mjs`将它作为独立的baseline字段发送。不是挪用某个内部启发式评分，也不是在模型异常时回退。缺少合法基准选择即报错。其他候选全部保留。

`model.py`给基准候选一个随候选数调整的先验分数，神经网络输出相加的修正。初始修正层为零，取最高分时精确选择1.5。随机训练初始将95%的概率分配给基准，其余5%均分给其他合法候选，只有一个候选时概率为1。初始随机训练策略不等同于1.5，不承诺探索过程维持1.5胜率。独立critic不会通过共享参数改变actor。

初始检查点`initial.pt`永久保留。后续强化训练可以改变最高分选择，也可以退步；上线或宣布胜出必须通过评测。已有纯模型不能直接加载成混合模型，检查点记录baseline版本、概率及局部推演版本。

## 当前推演的准确范围

`training/preview.mjs`仅接收既有脱敏观测，不接收Game、他人手牌、牌库或随机源。输出局部操作的检查点：

| 决策 | 已提供的信息 | 停止边界 |
| --- | --- | --- |
| 应战/圣光/魔弹响应 | 消耗牌后剩余手牌与独有技、牌进入field、响应分支 | 出牌曝光及后续触发；不预测最终伤害 |
| 爆牌 | 暗弃后剩余手牌及数量 | 士气及后续触发；不推断士气最终变化 |
| 提炼 | 个人能量与团队星石变化 | 行动结束触发 |
| 放弃额外行动 | 清空待执行额外行动 | 回合结束触发 |
| 其他 | 明确标记unresolved | 尚未实现推演 |

不是完整沙盘、搜索或所有英雄技能模拟。不把剩余手牌的独有技标签集合称为“技能一定可发动”。普通出牌可能先经历启动选择，因此暂不把其手牌扣除宣称为已经执行的结果。局部运算有与真实引擎对照的测试；后续扩展时继续验证，不能复制一套完整规则。

## 首轮实际结果

代码提交610eb2c；冻结运行快照的160个文件与该实现匹配（启动时为已暂存修改，源哈希及工作区补丁完整保留）。253项Node测试、17项Python测试通过。

576局训练完成，47855次模型决策，用时198.81秒，无截断。初始及训练后各完成504条开发评测记录（168整队、168混合模型席、168混合控制）。整队与混合均为84胜84负，和零调整版本的所有配对胜负相同；训练后16899次模型决策中7次偏离基准。

这证明初始1.5能力可保留、训练可修改选择，尚未证实强度提升。六个种子簇的配对差全为零，重采样区间也为零，不代表总体等效或无退化风险。最终独立种子未用，不标记“战胜1.5”目标完成，不更新线上版本。下一阶段应先分析稀少的有效调整和探索效率，不能将本轮持平包装成学习成功。

## 后续运行检查

在两组对照训练继续运行期间，补充完整评测清单审计与分层报告工具`training/evaluation_breakdown.py`：拒绝重复/缺失场景、错误阵容或策略、矛盾的结束标记及已改变的模型文件；整队与混合结果分开，报告七阵容、红蓝阵营、0/1先手及六英雄作为唯一模型席时的团队结果。英雄分层不等于单英雄强度，分层区间不作为多重检验校正后的验收门。原统计区间按种子簇等权，英雄子组局数不均时不与按局数加权点估计混为同一统计量。新增清单/分层检查与既有统计共4项测试通过；首轮504条实际记录通过审计。

硬件与吞吐检查保存在`evidence/residual-rollout-benchmark.json`和`evidence/residual-model-benchmark.json`（相对本地ML数据根目录）。固定父模型、48局、4/8/12/4进程实测分别16.30/12.86/12.69/16.09秒，对局摘要一致且无截断；四进程首尾接近，八进程约快26%，但有两组训练并行，不能声称隔离环境的稳定加速率，也不能把最终摘要相同当成逐决策证明。该证据支持后续登记阶段考虑八进程，当前两组四进程配置不变。

混合模型约232.8万参数，CPU/GPU输出在既定容差内一致。真实924候选爆牌输入、128批次的单次训练压力检查峰值已分配显存约825MB；这不是完整训练总显存或未来训练速度承诺。`training/benchmark_model.py`已适配显式基准输入，不再遗漏baseline字段。
