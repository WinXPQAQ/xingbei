# 噬神者：0.15.0 / AI 1.15.0-preview.1

噬神者成为第54位可选英雄。规则、专属牌和基础AI分别在`src/heroes/god-eater/index.js`、`ai.js`、`observation.js`。原文参考`character/shenZiChuangLin.js`，下述用户裁定优先于旧代码及FAQ。本次不启动机器学习训练。

## 采用的规则

- 魔刃是火／水、异刃是雷／风，两者均为血命格攻击专属牌。开局各注册一个实体在场外；御刃、共振、侵刻与移除始终操作原实体。删除手动转换属性技能。
- 渗蚀：离开持有者手牌，且不成为该持有者的盖牌时，由这把刃所属噬神者对原持有者造成3法伤。交牌不豁免。成为盖牌时，噬神者对盖牌持有者造成1法伤，然后移除刃。进入弃牌堆立即移除，不参与之后洗牌。
- 同调只将噬神者本人触发的3点渗蚀改为1点。普通角色、额外技能伤害均不套用同调。
- **诸神终焉直接移除不触发渗蚀。** 这是用户明确确认的“移除”语义；内部以`moveCard(..., {removal:true})`移动至场外。先获得水晶、自伤2；同时移除两刃；按顺位对每张刃原持有者各造成3法伤，同一持有者仍分别两次；同时移除两刃再对一名对手造成2法伤。任何一步获胜即终止后续。
- 侵刻在②可将正在使用的那张刃交给攻击目标；不创建替身牌、不预先移除场上攻击牌。噬灭／殇灭按①响应支付对应系别费用移除治疗；共振在受到法伤③支付水晶和2–3张同系牌，可取回场外一把或两把刃，取回后对目标造成1法伤。

## 移牌与嵌套结算

`moveCard`记录卡牌固有移动效果，`flushCardMoves`按整组移牌、深度优先插入的方式结算。卡牌效果留在英雄目录，共用引擎不判断具体英雄。攻击、交牌、技能费用、盖牌与爆牌接入同一流程；弃牌的曝光事件与隐藏性仍按既有规则处理。

- 爆牌先移动本次所有弃牌，再结算渗蚀，最后返回外层士气窗口。插入的3法伤具有独立摸牌、爆牌和月女响应，不和外层爆牌合并。
- 月女可以根据外层爆牌保留的实体引用，将刚移除的刃尝试作为暗月；产生1法伤并再次移除。消失的暗月不能承担相应的外层士气减免；暗月耗尽即退出形态。已经在嵌套效果中被其他技能收走的牌不会被强行夺回。
- 猎巫人直接将选中的手牌移到魔力瓶：取自己手中的刃只触发1伤，取他人手中的刃先对原持有者3伤、再对猎巫人1伤。取消原先经过弃牌堆的内部中转。
- 剑帝未命中、女仆长命中后盖放场上的刃会另触发1伤。魔弓整组盖牌全部放好后才插入渗蚀；其他盖牌技能同样在后续操作前处理。
- 王权宝珠的展示供牌属于特殊存放，不算这里的盖牌。将刃放上去会触发离手渗蚀，但不触发盖牌渗蚀；圣律威压要求弃专属牌，普通攻击／法术均不能代替。
- 其他技能在弃牌后再收取牌时，会检查实体是否仍在弃牌区。已被移除的牌不被泛化为“任何人都能从场外取回”；月女上述处理是本次明确指定的例外。

## 双属性决策

`src/card-sets.js`已有同系交集与不同系匹配。网页版现在用完整合法组合过滤每一步仍可选的牌，保留已选牌再次点击撤选：水＋魔刃合法，此时再选火非法；水＋火之后魔刃不可选。

`src/resolution/card-traits.js`负责本次使用的属性解释，不永久改变牌面：

1. 同系应战或限定额外行动只剩一个属性时，自动采用。
2. 主动攻击存在两个有意义的属性时询问，攻击上下文和使用曝光只携带选定属性。
3. 费用确认后保存满足单牌／整组条件的可行属性分配。明弃／展示只采用其中一种合法解释；若不同解释会触发不同的已注册效果，则询问玩家，允许避开封印。若已被费用限定则不再询问。
4. 暗弃不触发封印，不为隐藏弃牌额外询问公开属性。后续持有者获得牌后仍有原来的两个可用属性。

牌面、手牌提示和结构化观测保留双属性。公开刃的实体位置与原所属英雄可追踪；不开放其他普通手牌或牌库内容。两把刃的ID已纳入英雄状态契约。

## 基础AI及界面

噬神者保留刃和普通攻击，按手牌空间考虑御刃、共振取回数量；噬灭／殇灭只在有治疗可移除时倾向支付；诸神终焉估计自身损失、原持有者伤害和双刃额外伤害。攻击评分计入刃的离手伤害；属性选择优先避开已知封印。仍是局部估计，不宣称已达到高水平，尤其不穷举所有嵌套交互。

体验阵容：噬神者、月之女神、神官、魔弓、剑帝、猎巫人，六人红蓝蓝红红蓝。开局仍可选择全部54位英雄。新增1头像、2刃图片，原样复制并登记SHA-256，资源累计100份。

顺带修复共用选牌确认容器的空白区域拦截点击问题，仅按钮接受点击，保持原布局；月女AI在暗月选择与后续必弃手牌中区分请求类型，避免必选弃牌返回null。
