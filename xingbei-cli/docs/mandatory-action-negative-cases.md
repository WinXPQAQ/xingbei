# 给玩家的五个真实全负评分局面

先看局面，再自行判断应该做什么，最后展开AI估值。这里“全负”只指v1.3模型，绝非所有行动客观有害。均为自然对局，未为凑数构造手牌；按首次出现且英雄不同取样，样例来自v1.3对v1.0，不能据此估计全负发生率。

座位从0起，行动顺序0→1→2→3→4→5循环。红方固定座0/3/4，蓝方座1/2/5。只给本人手牌；其他人只给张数与公共资源/状态。没有全知手牌、未来牌库或暗牌日志。全量公开历史、卡牌属性/命格/独有技、所有候选完整分项与复现配置见[案例JSON](../artifacts/ai/mandatory-action/negative-cases.json)。

评分定义：期望结算后状态价值减去行动前状态价值。0分是“估计状态价值不变”的数学参考，不是合法的普通不行动选项，也不是胜率50%。手牌价值、牌量负担、士气、星石、效果和后续风险是启发式估计；反击/命中概率及有限额外行动搜索均可能估错。评分分项是团队视角，负值不一定表示本人受到同名伤害。正确规则下仍必须行动。
