# 英雄公开能力评估

入口是 `src/ai/hero-capabilities.js` 的 `estimateHeroCapabilities(state, playerId)`。各英雄的机制声明放在自身目录的 `capabilities.js`，印刷牌先验、同系组等公共计算放在 `src/heroes/shared/ai/capabilities.js`。这些函数不执行规则、不生成合法操作，也不修改状态。

输入沿用 AI 的隔离状态：玩家的英雄、手牌数量和上限、治疗、个人能量、公开英雄状态、公开附加效果、盖牌数量，以及观察者自己的手牌。其他玩家即使意外传入 `hand` 数组也不会读取；其牌面只能使用依法公开的 `known`。不读取牌库、暗盖牌或异教徒的私有预言面。未知牌按固定的 150 张印刷牌分布估计，不使用实际剩余牌堆。

规划器追加的 `reserve: true` 可使用盖牌与手牌分开：可以作为已知的魔弹/中毒出牌机会，但不占手牌数量，不当成弃手牌费用，也不增加手牌离手能力。

输出将三类能力分开：

| 字段 | 含义 |
| --- | --- |
| `spellThreats` | 法伤机会，包含技能、伤害、目标集合、最大目标数、时机分组和条件权重 |
| `drawThreats` | 非伤害的强制摸牌，例如神箭手狙击；不能减掉目标治疗 |
| `discard.self/ally/enemy` | 各自手牌离手能力；包含弃牌、支付牌、盖牌、交牌，不包括等量换牌带来的虚假净减压 |
| `turnover.draw` | 主动获得新手牌的能力 |
| `turnover.exchange` | 等量交换的吞吐，既不是净摸牌也不是净弃牌 |
| `turnover.selfDamageDraw` | 通过自伤获得手牌的能力，单独列出 |
| `normalPlay` | 普通出牌和明确额外行动的离手机会 |
| `flow` | 离手、进手、等量交换的分项摘要；进手不会直接加到减压得分上 |
| `coverage` | `modeled`、`baseline-only` 或 `unknown`，说明是否有专门声明 |

`readiness` 是启发式机会权重，**不是经过校准的发生概率**。有完整自家手牌时，牌种/属性门槛可以精确判断；别人的牌面只按公开数量估计。攻击未命中、结算基础效果、未来预言翻面等条件进一步折扣。单一事件的 `amountByTarget[id]` 优先于通用 `amount`。

相同 `route` 表示互斥行动，如用一次行动打魔弹或施放另一个法术，不能相加。一次群伤用一个记录加多个 `targets` 表示；瘟疫法师的全场伤害也包含队友。不同 `route` 仍可能争用同一张牌或同一颗能量，调用方必须折扣，不能把所有机会当作必然连招。该模块不是完整一回合搜索。

离手字段同样描述可选能力，不意味着所有动作同时执行。`flow.outgoing` 取普通出牌和技能离手能力的较大值，避免把技能费用与替代掉的普通行动重复计数；`incoming` 取摸牌与自伤摸牌能力的较大值，两个原始分项仍独立保留；不会把互斥路线相加。由于离手与进手上限可能来自不同路线，不提供可直接评分的“净减压”差值；`exchange` 保持独立。红莲的祷言和盛宴属于高进手吞吐，不能因此判断其擅长消除手牌压力。是否值得承受伤害应由爆牌、治疗、后续行动和胜负收益计算。

首轮 72 个注册英雄都有覆盖声明。其中 24 个提供专门估计：本批 14 英雄，以及红莲骑士、元素师、见习制片、苍炎魔女、贤者、祈祷师、神官、魔法少女、神箭手、魔弓 EX。其余 48 个明确为 `baseline-only`，保留魔弹和中毒等基本牌机会。**基础覆盖不等于该英雄没有专属法伤、弃牌或换牌能力。** `capabilityCoverage` 可以直接枚举缺口，之后随英雄策略逐步补充。

目前的简化包括：没有完整搜索共用资源；不推断未知盖牌的准确属性；预言翻面和史书翻牌只给保守机会；未覆盖所有受伤反应和队友连锁。它适合公共风险与低流速支援对象的轻量比较，不能替代引擎的合法性验证或把启发式数字当成胜率。

最小验证检查注册表的 72 项覆盖、结果数值有限、扰动他人手牌/牌序/私有预言面不改变输出。没有新增逐英雄固定打法测试。

一次性脚本和结果保留于 `artifacts/ai/hero-capabilities/check.mjs`、`report.json`；运行 `node artifacts/ai/hero-capabilities/check.mjs` 可重做 576 组通用检查，以及可用盖牌与手牌容量的分离检查，不加入日常逐英雄测试。


当前消费方为共享法术风险和灵魂链接选人。法术风险对每个敌人只取当前最强的一项威胁，不把多个技能累加；直接摸牌与法伤分别结算治疗、圣盾和保护。灵魂链接结合近期公开离手历史与 `flow.outgoing`，不使用高摸牌或等量交换来假定该角色能主动跑空手牌。

一次性验证脚本与报告保存在 `artifacts/ai/hero-capabilities/`，不是日常逐英雄打法检查；注册表和隐私不变约束同时并入原有 `test/ai.test.js` 隐私条目。


后续英雄策略正在增补能力声明，具体已覆盖名单以 `capabilityCoverage` 为准。用户已暂停所有检查，首轮576组结果不代表这些后续新增声明已验证。


当前实现另加入仲裁者、染污者、血色剑灵，专门声明增至27位，其余45位仍为基础估计。染污的 `noHealing` 标明禁疗伤害；魔弹型威胁的 `responseKind` 用于扣除圣光/传弹的响应覆盖，普通直接法伤不因此减免。公共未来估计没有完整消耗连续攻击共用的治疗与响应牌，也没有展开传弹整圈，结果只用作折扣风险，具体行动仍由局部决策计算。
