# 四种开局模式（v0.16.1）

网页版开局和重新开始先选模式，再为六席逐一指定角色。坐次按逆时针为红一、蓝一、蓝二、红二、红三、蓝三；每个位置必须选择已实现角色且不能重复，选齐后点击“开始对局”才初始化英雄、专属牌并发牌。角色列表包括当前72位。取消某个位置的选择后可重新分配；不保存上次模式或阵容，不受旧`HERO_PREVIEW`默认阵容控制。终端选角、训练阵容和固定开发场景不受此网页入口修改影响。

| 模式 | 控制 | 调试与可见性 |
| --- | --- | --- |
| 正常 | 0号手动，其余AI | 隐藏其他手牌，无调试操作 |
| 测试 | 0号手动，其余AI | 全手牌可见；空闲时摸牌、暗弃牌、红蓝士气±1；自己回合结束可重复 |
| 观战 | 六席全部AI | 全手牌可见，暂停／继续 |
| 开发者 | 六席及所有决策均手动 | 全手牌可见；当前席位摸牌、暗弃牌、红蓝士气±1、推进下一回合 |

开发者模式在行动开始时切换到底部显示当前角色。响应、治疗、技能、选目标、爆牌等临时决策会切到实际决策者，完成后返回原控制席位；工具栏明确显示座位、阵营和角色。无需代替该角色点击“自动”，不会安装模型代理，也禁止引擎自动决策兜底。

调试按钮仅在空闲行动选择时开放。摸牌、弃牌仍调用共用规则，正常处理爆牌及卡牌离手效果；选牌必须确认，取消不移牌。处理技能、选牌、选目标、动画时禁用调试按钮。“推进下一回合”只跳过尚未执行的行动／额外行动，保留现有牌和资源，继续执行行动阶段结束、回合结束及其技能，再按TurnFlow的顺位／额外回合安排推进。它不是强行中断正在结算的攻击，也不绕过胜负。

隔离：`web/developer-mode.js`只提供显式模式校验后的跳过入口，普通规则引擎没有新增免费行动。调试命令还检查当前模式、就绪和空闲状态；普通模式即使触发隐藏按钮也无效。重开取消Session的全部等待，重置到0号视角和新模式，不把先前开发者权限带入普通局。`/web/dev.html`仍是原固定场景工具，不等于新增“开发者模式”。

验证：142项核心规则测试、8项UI／会话单元检查通过。桌面1440×900和触屏390×844下，四模式／阵容／六席操作109项浏览器检查通过，包括手动对手响应、治疗与爆牌、重开隔离。固定手牌的响应链属于隔离准备，不作为自然对局统计；未重做原版全部视觉对照。证据在`artifacts/modes/manual-seats/`，工具为`tools/verify-hero-selection.mjs`。共用应战／魔弹／暗弃回归另155项通过，证据在`artifacts/modes/manual-responses/`。两套合计264项浏览器检查，无控制台或素材错误。

部署：4174更新至本次main发布目录，标识为`测试0.16.1 + AI 1.16.0-preview.1`，包含3811120的空手不能换牌修复和全部特典；4173不手动调整，训练任务不改动。

# 开局游玩模式（v0.6.1）

网页版开局和重新开始先选择模式，再选择六位已实现角色之一。座次仍为红蓝蓝红红蓝，选角替换/交换0号位。开发场景保持直接进入固定场景，普通对局不自动保存上一次模式。

| 模式 | 控制方式 | 额外功能 |
| --- | --- | --- |
| 正常游玩 | 玩家控制0号，其余AI | 隐藏其他角色手牌，不显示测试按钮 |
| 测试游玩 | 玩家控制0号，其余AI | 摸1张、选择暗弃1张、红/蓝方士气各±1、自己回合结束后选择是否重复 |
| 观战游玩 | 包括0号位在内全部AI | 为0号AI选角色，随时暂停/继续 |

测试和观战会在每个角色下方显示手牌图标，复用原牌图，尺寸与状态图标相同（26×26逻辑像素，随整个对局缩放）。图标的标题/无障碍文字包含属性、命格和独有技。为容纳0号角色下方的图标，这两个模式单独上移其头像；正常模式位置保持不变。其他玩家公开的手牌图标仅用于显示，不传给AI作为额外决策信息。

测试按钮在玩家自己的空闲行动选择时可用，选牌、选目标、结算和动画期间禁用，避免与正在结算的流程交叉修改。测试弃牌需要选牌后确认，可再次点牌、取消或Esc撤回。测试摸牌仍使用正常的爆牌选择和士气损失流程；士气按钮沿用规则上限15，到达胜负条件会正常结束游戏，上限时增加按钮禁用。

重复回合不是回滚：先执行当前回合的全部结束时点，再询问“重复回合 / 不重复”。重复时保留当前牌、能量、士气和状态，通过TurnFlow.repeatLast重新进入0号完整新回合，重新初始化启动/攻击次数/额外行动；下一回合的状态触发仍正常执行。未重复则按原座次继续，已结束的游戏不再询问。

观战暂停使用Session绑定的PlaybackGate，在行动、响应/技能决策、呈现事件前后阻止继续；同时暂停当前动画。关闭动画也可以暂停。正在执行的同步规则步骤不会被截断，停在下一检查点；重开取消旧会话的等待和动画，不会让旧AI串入新局。

实现位于 `web/play-mode.js`、`web/app.js`、`web/render.js`、`src/turn.js`，不引入依赖。测试入口继续复用 `tools/verify-hero-selection.mjs`，扩展现有开局选角检查，未另建重复浏览器工具。

验证：71项Node测试通过；1440×900桌面和390×844触屏下开局/模式89项、整体86项、响应155项，共330项浏览器检查通过，控制台和素材错误0。模式验证包含真实点击摸牌/弃牌、取消、爆牌选择、双方士气、重复/不重复、正常模式隐藏、六座位自动回合、开关动画时暂停/继续、暂停中重开及图标边界。截图与结果见 `artifacts/modes/validated/`、`frontend/`、`responses/`。首轮窄屏测试发现工具栏遮挡手牌，已调整位置并复验；原失败证据保留。

此功能为用户明确要求的额外测试界面，不属于旧版视觉还原；不能把这批结果描述成完成全部原版视觉验收。页面顶部的TEST_MODE版本标记与本次游玩模式是两个独立开关。
