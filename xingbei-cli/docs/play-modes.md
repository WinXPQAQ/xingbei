# 开局游玩模式（v0.6.1）

网页版开局和重新开始先选择模式，再选择六位已实现角色之一。座次仍为红蓝蓝红红蓝，选角替换/交换0号位。开发场景保持直接进入固定场景，普通对局不自动保存上一次模式。

| 模式 | 控制方式 | 额外功能 |
| --- | --- | --- |
| 正常游玩 | 玩家控制0号，其余AI | 隐藏其他角色手牌，不显示测试按钮 |
| 测试游玩 | 玩家控制0号，其余AI | 摸1张、选择暗弃1张、红/蓝方士气各±1、自己回合结束后选择是否重复 |
| 观战游玩 | 包括0号位在内全部AI | 为0号AI选角色，随时暂停/继续 |

测试和观战会在每个角色下方显示手牌图标，复用原牌图，尺寸与状态图标相同（26×26逻辑像素，随整个对局缩放）。图标的标题/无障碍文字包含属性、命格和独有技。为容纳0号角色下方的图标，这两个模式单独上移其头像；正常模式位置保持不变。其他玩家公开的手牌图标仅用于显示，不传给AI作为额外决策信息。

测试按钮在玩家自己的空闲行动选择时可用，选牌、选目标、结算和动画期间禁用，避免与正在结算的流程交叉修改。测试弃牌需要选牌后确认，可再次点牌、取消或Esc撤回。测试摸牌仍使用正常的爆牌选择和士气损失流程；士气按钮沿用规则上限15，到达胜负条件会正常结束游戏，上限时增加按钮禁用。

重复回合不是回滚：先执行当前回合的全部结束时点，再询问“重复回合 / 不重复”。重复时保留当前牌、能量、士气和状态，通过TurnFlow.repeatLast重新进入0号完整新回合，重新初始化启动/攻击次数/额外行动；下一回合的状态触发仍正常执行。未重复则按原座次继续，已结束的游戏不再询问。

观战暂停使用Session绑定的PlaybackGate，在行动、响应/技能决策、呈现事件前后阻止继续；同时暂停当前动画。关闭动画也可以暂停。正在执行的同步规则步骤不会被截断，停在下一检查点；重开取消旧会话的等待和动画，不会让旧AI串入新局。

实现位于 `web/play-mode.js`、`web/app.js`、`web/render.js`、`src/turn.js`，不引入依赖。测试入口继续复用 `tools/verify-hero-selection.mjs`，扩展现有开局选角检查，未另建重复浏览器工具。

验证：71项Node测试通过；1440×900桌面和390×844触屏下开局/模式89项、整体86项、响应155项，共330项浏览器检查通过，控制台和素材错误0。模式验证包含真实点击摸牌/弃牌、取消、爆牌选择、双方士气、重复/不重复、正常模式隐藏、六座位自动回合、开关动画时暂停/继续、暂停中重开及图标边界。截图与结果见 `artifacts/modes/validated/`、`frontend/`、`responses/`。首轮窄屏测试发现工具栏遮挡手牌，已调整位置并复验；原失败证据保留。

此功能为用户明确要求的额外测试界面，不属于旧版视觉还原；不能把这批结果描述成完成全部原版视觉验收。页面顶部的TEST_MODE版本标记与本次游玩模式是两个独立开关。
